# 安全与备份

## 存储边界

| 文件                                                   | 内容与保护                                                                                                                         |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `profile.json`                                         | 本机姓名与头像，明文                                                                                                               |
| `main-identity.enc`                                    | Linux.do 主身份资料、登录服务凭据、同步偏好、已缓存头像及帖子，使用 Electron safeStorage 系统加密，独立于主密码库                  |
| `assets.json`                                          | 资产元信息、关联、邮箱分组、账号头像及自定义发件人头像和地址对应关系，明文                                                         |
| `conversations.json`                                   | 问答及来源，明文                                                                                                                   |
| `documents/`                                           | 工作区文档、网页正文快照与来源链接，明文                                                                                           |
| `knowledge.json`、`rag-index.json`、`rag-vectors.json` | 导入文档和检索缓存，明文                                                                                                           |
| `metrics.json`                                         | 指标历史，明文                                                                                                                     |
| `local-usage.json`、`usage-events-*.sqlite`            | 本机用量索引指针、事件指纹、汇总计数及读取检查点，明文；不包含提示词、回答正文或凭据                                               |
| `local-usage.json.v1-*.backup.json`                    | 升级用量索引前保留的原始统计缓存副本，用于恢复核对                                                                                 |
| `vault.enc`                                            | 主密码派生密钥保护的 AES-256-GCM 网站/邮箱/SSH 凭据、AI 账号 OAuth 令牌、旧版身份接入配置与令牌、TOTP 密钥、邮件推送配置和邮件草稿 |
| `agent-config.json`                                    | 模型配置，其中 API Key 使用 Electron safeStorage 加密                                                                              |
| `mailbox-baselines.json`                               | 邮箱 UID 检查基线，明文；不保存邮件内容或认证凭据                                                                                  |

数据目录在「设置 → 数据」查看。Windows 通常位于当前用户 AppData 下的 Nanpad 目录，以界面实际显示为准。

1.7.0 的本机用量索引使用 SQLite 事务同步保存去重记录、统计与读取位置。备份时应正常退出应用后复制完整资料目录，不能只复制 `local-usage.json` 指针文件；新索引迁移保留旧缓存副本，历史补采复用完整去重信息。

## 主密码

首次创建至少 10 位，修改主密码时新密码同样至少 10 位，上限 256 位，由桌面主进程强制，不只依赖界面提示。应用不保存主密码，不提供密码找回。升级时原有密码继续可用，修改密码需要输入原密码。密钥库损坏时拒绝创建覆盖，先保留原文件并检查备份。

主密码经 scrypt 派生 AES-256 密钥。新建密钥库与修改主密码时使用 N=2¹⁷、r=8、p=1（每次派生约 128 MiB 内存），参数随 v2 密钥库文件保存，并严格限制内存与运算量。1.7.0 及更早版本创建的 v1 密钥库继续按当时的 N=2¹⁵ 解锁，普通读写保留 v1，修改主密码才升级到 v2。已有短密码仍能解锁，升级后的 v2 库不应再交给旧版本程序写入。

运行期间若外部恢复了备份，下一次读取会核对文件身份与解密密钥；同密钥的备份可以重读，不同盐、参数或校验密文会锁定旧会话并通知界面隐藏凭据。每个写入操作在提交前检查自己读取的文件快照，期间文件变化则取消操作并锁定，首次创建也不覆盖已出现的文件。文件暂时缺失或被目录占位时，原缓存仅供读取，不允许保存。这些检查不构成跨进程的操作系统级比较交换，仍应先退出应用，再备份或恢复完整数据目录。

锁库保护凭据，不是整个应用的登录锁。资产与对话仍可见，操作系统安全存储加密的模型 Key 和 Linux.do 主身份也不由主密码派生。主身份登录不需要解锁密钥库，也不能代替主密码解密资产凭据或找回主密码。因此不要把未加密的本机资料视为密码保险箱。

## 网络边界

SSH、邮箱探测、WHOIS、TLS 和模型请求会连接填写的远程服务。用户问题、历史上下文和命中文档会发送到配置的模型。OAuth 只连接适配器指定的供应商端点，不接受渲染进程传入任意 Token URL，也不记录服务返回的令牌正文。

网站账号的登录地址、用户名、密码和加密账号备注不会进入自动资产索引或资产 JSON 导出。资产普通名称、提示、标签和说明仍是明文；用户把密码手工放进提问、近期对话或导入文档后，不能依靠凭据库的隔离保护这些副本。

凭据定位只返回本机资产位置，不读取加密库、不确认密码是否存在。实时邮箱工具需要用户为当前问答启用「本次允许查询邮箱」；本机服务用已保存凭据完成 IMAP TLS 认证，只把数量和时间交给模型。Agent 使用的数量查询不下载标题、正文和附件，不自动标记已读。邮箱登录密码仍会作为认证材料发送给用户配置的邮箱服务，不能把“不发给模型”理解为“不离开本机”。

本地邮箱目录工具可查询分组名称、账号数量、邮箱地址、类型及归属，不连接邮箱服务器，也不需要实时查询许可。这些元信息会发送给配置的模型，密码、邮件正文、草稿、账号图片和自定义发件人头像映射不进入工具结果或自动资产索引。用户主动输入到问题、对话或导入文档中的副本不受这条字段白名单保护。

邮件工作台由用户直接操作，通过 IMAP 读取邮件和附件，通过 SMTP 发送确认后的内容。HTML 在主进程使用白名单净化，再由阅读器只展示允许的静态元素和有限文字样式；脚本、表单、嵌入网页及外部样式被移除。纯文本邮件可按 Markdown / GFM 排版，也可查看解析后的原文。正文不进入 Agent/RAG 索引；退出阅读区或锁库后清除界面内存。

正文外部图片默认不会发出请求，只有点击「加载本封图片」后才加载；授权按邮件记忆，最多保留 500 封，可在「设置 → 存储」清除。图片请求不携带页面 Referer，但图片服务器仍可能得知 IP 地址、访问时间和 URL 中的跟踪标识。点击隐藏不能撤回已经发出的请求。符合格式、尺寸和数量限制的 CID 内嵌图片来自已经读取的邮件，在本机展示；应用不自动向外部服务查询发件人头像。本地自定义头像及对应地址是明文资产数据，导出资产时也会带出。

每个邮箱的本机草稿包含正文、收件人与附件，保存在 `vault.enc`。手动下载附件会生成用户选择的普通文件，不再受主密码库保护。SMTP 只接受 TLS 或强制 STARTTLS 并验证证书；锁库取消进行中的连接，但已被服务商接受的邮件无法撤回，结果不明时不会自动重发。

邮件推送默认关闭，用户保存配置后才启用。Bot Token、SendKey、机器人 Key、WxPusher AppToken 和目标配置保存在主密码库，接口返回给界面的配置不含令牌。通知发送到选定渠道的固定 HTTPS 端点，只含新增数量、相关邮箱未读数量及检查时间，不含邮箱地址或邮件内容。渠道本身会接收到通知和必要的认证信息。锁库或退出后停止新的检查及推送；已被远端接收的请求无法撤回。第三方网络超时重试可能出现重复通知。

文档和模型回答的 Markdown 不执行原始 HTML，不自动请求远程图片；邮件正文使用上述单独的图片许可。两者均不允许 `javascript:` 等外链协议，外部 HTTP/HTTPS 链接交给系统浏览器打开。

缓存边界（0.9.0）：问答检索索引缓存只含资产白名单元信息与导入文档片段，与模型上下文同界；邮件正文、附件与列表的会话缓存只存在内存，锁库或标记已读即清除，不落盘；远程图片授权记忆只保存邮件 Message-ID 列表（界面偏好，不含图片地址或内容），存于浏览器本机存储，可在「设置 → 存储」清除。缓存不会主动读取主密码库的密码、令牌或密钥值；用户自行写入文档或问题的敏感文本不能被保证自动脱敏。

## 与网页版同步

桌面版可以与自己服务器上的网页版配对并同步，协议、威胁模型和参数见 [SYNC.md](SYNC.md)。安全边界：配对用一次性配对码做 PAKE，之后每次同步用固定的 Ed25519 设备密钥与服务器密钥互相认证，并用 X25519 临时密钥协商的 AES-256-GCM 会话加密，纯 http 下也不会被中间人读取或篡改；设备私钥保存在系统安全存储中（只提供明文存储时拒绝保存）。密钥库默认不同步，开启后只传密文，服务器看不到明文；系统加密保存的 Token 与 API Key 永远不参与同步。服务器被入侵时，攻击者可以读取并修改**不在密钥库里**的资产与文档，这与网页版本身的保存方式一致。

## 浏览器密码迁移

Chrome / Edge 密码迁移使用浏览器官方导出、导入的 CSV，不读取原生密码数据库或绕过操作系统身份验证。CSV 只在桌面主进程解析；渲染界面接收不含密码的预览和短期票据。确认后批量写入 AES-256-GCM 主密码库；关闭、取消、过期或锁库会撤销尚未提交的预览。相同站点不同用户名分别保存，完全重复跳过，导入密码冲突保留现有记录、不自动覆盖。

预览中的网站、用户名与标题仍是个人信息，截图时应检查。导入完成后的普通资产数据不含账号网址、用户名和密码，但保留显示名称等元信息。加密记录同时保存可恢复的资产描述，避免写入凭据后意外退出导致找不到账号。

导出需要解锁、界面明确勾选和系统再次确认，只导出可用于浏览器密码管理器的账号记录。CSV 包含**明文网址、用户名、密码及敏感备注**，不受主密码库保护；应保存在自己控制的目录，浏览器导入后删除，不共享或用表格软件打开。文件保留真实密码字符，不能用给公式前缀添加字符的方式改变密码。资产 JSON 导出仍不包含这些凭据。

## Linux.do 身份、帖子与文档账号提取

主身份登录入口在首次设置和个人资料。普通用户无需提供 Client ID 或 Client Secret，统一通过 `https://auth.allinsong.top` 登录服务接入 Linux.do Connect；共享 Client Secret 仅存于服务端，官方回调为 `https://auth.allinsong.top/oauth/linuxdo/callback`。登录服务接收本次官方授权结果并向固定官方端点换码，不接收工作区资产、文档或主密码。

系统浏览器完成官方授权后，服务端通过绑定桌面 PKCE 的短时一次性交接码返回本机；桌面主进程在随机端口监听 `127.0.0.1` 并验证 Host、路径与 state。桌面至登录服务、登录服务至官方授权分别使用自己的 state 和 S256 PKCE，回调地址不携带官方令牌。主进程换得登录服务加密凭据，渲染界面仅接收身份资料和授权状态，不接收服务凭据、官方令牌或 Client Secret。登录服务凭据本身仍是访问凭证，不能公开分享。

授权成功先显示预览，用户确认后才绑定主身份；更换为另一平台身份需要再次明确确认。主身份资料、服务凭据、同步偏好、已缓存头像和帖子存入 `main-identity.enc`，由操作系统安全存储加密，独立于资产密钥库。系统加密不可用或 Linux 后端仅提供 `basic_text` 时拒绝保存，不降级为明文。取消或过期的授权预览不能继续绑定，锁定资产密钥库不退出主身份。

邮箱、等级等字段以平台实际返回为准，缺失时显示未提供，不根据用户名推测。平台返回邮箱可能是隐私地址，不证明可用作真实联系地址。昵称和头像同步默认关闭；开启同步只改变显示来源，保留原有本机自定义值。实际手动修改某个字段会关闭对应同步，仅保存相同内容不会关闭同步。只有选择头像同步时才按可信 Linux.do HTTPS 地址下载头像，失败时保留已有头像。

退出登录清除本机服务凭据与帖子缓存，保留身份资料、同步偏好及已保存文档；后续刷新资料或读取帖子需要重新登录。退出不会撤销其他设备会话或平台授权，平台侧授权需另行撤销。旧版从密钥库导入的身份记录、TOTP 和文档关联继续按原方式保护，绑定主身份不会改写或删除它们。

帖子请求发往 Linux.do 的公开接口，不携带 Connect 令牌或浏览器 Cookie。保存全文前核对帖子编号和作者，失败项明确报告，不使用摘要替代正文；公开访问遭拒时不会绕过验证。帖子列表与全文缓存复用 15 分钟，全文按用户选择读取。保存为文档后，全文与来源进入普通 `documents/` 文件，不再具有身份缓存的加密保护。主身份不是账号资产，保存文档时不会创建指向不存在账号的关联。

文档账号提取只在本机解析明确字段和表格，用户可查看及修正候选后选择保存。预览票据 5 分钟有效，锁库或取消即失效；保存前复核文档版本。凭据批量写入加密库，文档只新增账号引用。账号保存与文档关联若有部分失败，界面分别说明，不把凭据写入失败当成成功。

提取不会清除文档中原有的账号密码。原文、用户导出的 Markdown、允许模型读取的正文及已保存对话中的副本不会自动转为密文。提取出的密码不主动发送给模型，但用户主动授权包含密码的原文仍可能将其发送出去。

## 网站 TOTP 动态验证码

TOTP 密钥由主进程保存在独立的加密记录中，普通凭据接口不能读取身份私有配置或 TOTP 密钥。界面仅在用户填写时暂存新密钥，保存后清空输入；后续只获取配置摘要和当前验证码。锁库后清空界面验证码并拒绝新的读取，删除账号也会删除对应本机验证码配置。

复制验证码会将短期有效的明文代码写入系统剪贴板。TOTP 不替代主密码，也不为密钥库增加第二个独立保护因素；账号密码和 TOTP 密钥都保存在同一主密码库。删除本机配置不会关闭网站的两步验证。

## 浏览器插件

1.3.1 插件自动识别顶层网页的可见登录表单，用户也可打开弹窗核对。默认开启的「登录时自动采集」在提交时读取该表单或就近容器的账号密码，先显示保存提示；用户确认后才直接写入知屿加密库，无需桌面二次确认。关闭该开关会停止提交采集，账号建议与文档提示有独立开关。插件不访问浏览器原生密码库、Cookie 或浏览历史，采集结果来自网页，仍可能识别错误。

桌面连接只监听 `127.0.0.1:47832`，不监听局域网地址。生成配对码需要解锁密钥库；随机配对码包含 64 个十六进制字符，5 分钟有效、使用一次后失效。后续请求使用绑定扩展来源的随机令牌认证，服务检查来源、Host、请求格式、大小及频率。普通网页不能直接调用此保存接口。

账号密码走认证的本机 HTTP POST，不放进 `nanpad://` 链接、URL 查询参数或日志，也不经云端转发。本机 HTTP 不是 TLS 加密通道；这些校验不能防御已经控制本机或浏览器进程的恶意程序。只记录站点的旧入口使用 `nanpad://`，仅传网站名称及去掉路径、嵌入凭据、查询参数和片段的站点根地址。

账号建议按精确 origin（协议、域名和端口）匹配，不扩大到子域名。用户选择后才读取密码并填写，不自动提交登录。桌面使用绑定客户端、站点与候选账号的一次性短期选择票据；扩展后台同时核对标签页、顶层 frame 和导航状态，防止跨站读取或填入已经跳转的页面。远程 HTTP、隐藏字段、注册/改密表单、iframe、封闭 Shadow DOM 与第三方 OAuth 不作为自动填写目标。

提交后待确认的凭据仅在扩展后台内存保留，最多 2 分钟；休眠、关闭标签页或失去连接可能提前失效。确认后密码写入主密码库，不进入普通资产快照、自动 RAG 索引或模型上下文。站点名称、标签和普通说明仍是明文元信息，应检查网页标题是否带有个人信息。旧版插件的桌面待确认队列继续兼容，最多 10 条、每条 5 分钟；锁库、撤销连接或退出会撤销桌面授权并清除其待确认队列。

扩展把连接令牌保存在 `chrome.storage.session`，开关偏好保存在本机存储；不使用浏览器同步存储或持久化保存密码。浏览器会话结束后需要重新配对。连接令牌不交给网页，配对码、选择票据和令牌不要放进截图、问题报告或网页输入框；主密码始终在知屿桌面端输入。填写后网站自身可以读取其输入框，请核对访问的网站。本机控制权被窃取、浏览器被恶意扩展控制或账号目标站点被入侵，不在这些检查能够完全防御的范围内。

文档提示自动出现，但点击保存后才提取已加载的可见正文。内容以纯文本和来源链接写入普通本机文档，不执行网页脚本，不保存表单、隐藏内容或未加载页，不绕过访问权限；同来源去重并保留已有本机编辑。网页文档不属于凭据保险箱，其正文与其他工作区文档一样，只有在本次问答获得正文许可时才可发送给模型。

## 备份

1. 从托盘退出知屿，确保文件写入已经结束；数据目录名称仍使用 Nanpad。
2. 将完整数据目录复制到受保护的位置，备份文件包含个人元信息和加密凭据。
3. 单独妥善保管主密码。
4. 恢复前先备份当前目录。跨机器恢复后，操作系统加密的 API Key 和主身份文件可能无法解密；API Key 需要重新录入，主身份需要处理原文件后重新登录，操作前保留备份。主密码库使用原密码解锁。

资产 JSON 导出不是完整备份，不包括主密码库、聊天记录和 AI 授权。分享问题报告前移除主机地址、账号、Key、Token、文档和对话内容。

公开源码前还应检查 Git 历史、文档附件和截图；在新提交中遮挡图片不能移除历史版本中的信息。分享 OAuth 问题时不要附上完整回调链接，因为其中包含一次性授权码和会话状态。

## 1.2.0 文档授权与本机用量

工作区文档默认只有标题、时间与关联元信息可进入问答上下文。正文需要每次发送前明确授权；授权片段发送至配置的模型服务，并可能保存在本机问答历史。未再次授权时，带正文使用标记的旧回答不会回传模型。该开关不撤回服务商已经收到的内容，也不替代文档与聊天文件的本机访问控制。

本机 Token 监控只解析支持客户端日志中的用量数字与必要去重标识。持久缓存不保存提示词、回答正文、凭据或原始日志路径；只读扫描限定可信根，拒绝根下的链接逃逸、硬链接文件和文件替换。1.4.0 起默认开启且无需解锁，锁定主密码库不暂停用量采集；可手动关闭并保存选择。它不读取密钥库，不改变邮箱、账号、远程 API 等凭据功能的授权。

Windows 系统透明重定向仅对应用自己的统计缓存开放兼容：逻辑路径与实际路径均不得含符号链接，必须指向相同文件身份。该兼容不放宽客户端日志目录的路径校验，不申请管理员权限，不清空已有统计。

## 1.5.0 关联、修改建议与缓存

关系图只展示实际保存的资产关联和文档绑定。本机「发现关联」读取资产名称、主机／域名、标签和文档标题，不读取账号凭据或文档正文，不请求模型；匹配依据随建议展示，用户确认后才保存。同名、同标签不是已确认关系。

AI 修改工具需要本次开启「生成修改建议」；文档局部替换还需要本次正文许可。工具仅在主进程内存暂存待审阅建议，由主进程签发随机标识，30 分钟后过期；重启后不能继续应用旧建议。建议的依据及修改前后预览会随问答保存到明文对话历史，文档正文许可不意味着这些预览会加密。

点击「确认应用这项修改」后，主进程按建议标识查找原提案，核对目标仍存在且版本未变，再保存。界面不能用该入口提交任意替换载荷；过期、已忽略、已应用或内容已变化的建议会被拒绝。文档仅允许在一个文本节点中唯一匹配的局部替换；账号仅允许普通名称和标签，用户名、登录网址、密码和敏感备注仍通过本机加密账号面板维护。关联建议支持资产之间、文档与资产之间的连接，不复制凭据到文档。

重试使用当前模型配置与当前勾选的权限，不自动沿用失败问答的正文或邮箱许可。修复重试入口不代表 API Key、账号权限或服务端鉴权已通过；仍需在模型设置中使用有效配置。

解锁入口移到侧栏底部与账号详情，解锁后继续原操作。本次运行保持解锁，手动锁定、系统锁屏、休眠或退出后重新锁定；没有新增主密码持久化或跨启动自动解锁。锁库仍不隐藏明文资产、文档与问答，也不暂停本机 Token 统计。

用量界面使用内存快照，10 秒内复用读取，切页可先显示上次结果；远程用量自动采集在最近成功或失败尝试后的 5 分钟内复用状态，自动主机检查在所选采集周期内复用结果。手动刷新不受上述有效期限制，失败保留旧统计并显示错误；缓存结果不能视为刚刚完成的实时查询。文档变更通过增量通知更新受影响条目的缓存，旧式无变更详情的通知才重新读取列表；资产与知识文件变化会使检索索引更新。缓存不新增对密钥库的读取，也不把主密码或加密凭据复制到普通统计文件。

## 1.5.2 标题修改与授权续问

文档重命名仅需要本次修改建议许可，不需要把正文发送给模型。主进程使用当前标题验证目标，在本机保留完整文档用于版本校验与保存；提案公开结果只返回标题前后对比。用户确认前不写入，原标题不匹配、文档已变化或被删除时拒绝覆盖，正文、格式与已有绑定沿用原保存流程。

`request_workspace_access` 只生成授权提示，不能直接提升模型权限。本轮未允许的正文读取或提案工具，即使模型在申请权限后继续调用也会被拒绝。界面显示本次所需权限及用途，由用户点击后携带明确许可继续原问题；下一条问题重新确认。正文授权意味着相关片段可能发送至所选模型，不代表授权读取加密凭据或直接保存修改。

本机用量扫描完成后发送统计变更通知，有新记录才更新统计缓存；单纯采集状态变化不会重新读取全部统计。它不增加日志可读范围、管理员权限或远程请求，仍只读取受支持客户端实际写入的记录。今日明细与小额用量圆点使用原始聚合数值，不制造零值、缺失日期或实时消费记录。

## Cloudflare 与独立探针

Cloudflare API Token 和探针服务端管理 Token 保存在 `integrations.json` 的系统加密字段中，使用 Electron safeStorage；系统加密不可用或 Linux 退回 `basic_text` 时拒绝保存和读取。连接名称、地址和资产来源引用为普通元数据。此配置独立于资产密钥库，锁库不暂停监控；它不能抵御已控制当前操作系统用户会话的攻击者。Token 不进入资产导出、渲染进程配置返回值、日志或普通错误信息；新增 Agent 的凭据只在注册后显示一次。

Cloudflare 请求固定使用官方 HTTPS API，禁止跟随重定向。探针桌面连接使用 HTTPS，只有显式启用的本机/私网 IP 才允许 HTTP；不会自动忽略证书验证。Token 为空代表保留旧值；更换服务端地址必须重新填写凭据。连接修改、移除后取消旧请求，迟到响应不能覆盖新缓存。资源读取和历史采用短期内存缓存及并发合并，不把未知或已离线状态显示为健康。

DNS 新增、修改、删除必须先由主进程生成一次性预览，票据两分钟过期，重启后失效。执行前再次核对连接版本和原记录，其他工具已修改的记录拒绝覆盖；网络超时后不自动重试写入，应先刷新确认实际结果。远端导入只保存公开字段，重复导入保留本地名称、备注和标签，不自动创建推测的资产关系。

探针 Agent 只采集主机指标，无终端、远程命令或文件读取 API。独立服务端使用管理 Token 与每主机独立随机凭据；主机凭据以摘要保存，撤销后中止已有上报流。公网默认 TLS，HTTP/TCP 检查允许用户自身内网，但拒绝云元数据、link-local、多播和未指定地址，并对解析、跳转、超时、并发及历史容量设边界。部署方式与实际支持的指标见 `services/probe/README.md`。
