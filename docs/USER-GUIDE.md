# 使用教程

## 安装与升级

当前正式版为 1.15.0。从仓库 Releases 下载 `Zhiyu-1.15.0-setup.exe`，适用于 Windows x64；免安装可使用下文的便携版。安装后打开知屿，新用户可以使用默认工作区名称，设置 10 至 256 位主密码；无需注册，头像可稍后设置。升级用户输入原主密码完成资料设置，已有 6 位主密码仍可解锁。不要删除数据目录来解决启动问题，先备份再排查。

在「设置 → 个人资料」修改名字或头像，点击「保存」后生效；在「设置 → 密钥库」修改主密码。修改主密码需要原密码，新密码要求 10 至 256 位，并将旧密钥库升级到当前加密参数；仅解锁或普通读写不会升级旧库。关闭窗口默认进入托盘，托盘菜单可以重新打开、锁库或退出。

1.7.0 起支持在首次设置或「设置 → 个人资料 → Linux.do 主身份」登录并绑定社区账号，也可以继续仅在本机使用。此登录不代替本地主密码，不上传资产；普通用户无需申请 Connect 应用或填写 Client Secret。具体步骤见[主身份与个人资料](MAIN-IDENTITY.md)。1.6.0 的密钥库身份资产继续保留，升级不会自动把它们改成主身份。

点击窗口顶部的「系统设置…」图标打开设置。「解锁密钥库／锁定密钥库」固定在左侧导航底部，收起导航后仍可点击对应图标。需要凭据的操作会直接弹出解锁框，解锁后继续原操作，取消时保留当前页面。本次运行内无需因保存或切换页面重复解锁；手动锁定、系统锁屏、休眠或退出后会重新锁定，不保存主密码用于下次自动解锁。

在「设置 → 关于 → 软件更新」检查新版本，点击「下载更新」查看进度。完整下载并校验后，点击「重启并安装」；软件先保存文档，再安装到当前目录并重新打开。下载失败可重试，原数据目录继续使用。旧版 1.2.3 尚无应用内安装能力，需要先安装一次 1.4.0 或更新版本，之后的版本即可在应用内更新。Windows 若提示系统权限确认，请按安装器提示操作。

### 便携版（免安装）

从 Releases 下载 `Zhiyu-x.y.z-portable-x64.zip`，解压到任意可写入的文件夹（例如 `D:\Zhiyu` 或 U 盘），双击 `Zhiyu.exe` 即可使用。不要解压到 `C:\Program Files` 等受保护目录。

- 程序目录中的 `portable.txt` 让知屿以便携模式运行，资料全部保存在同目录的 `data` 文件夹；删除该文件后会改用安装版的系统资料目录。
- 「设置 → 关于知屿」显示当前运行模式和资料目录。便携版可以检查新版本，但不会自动安装：下载新的便携压缩包，退出知屿后解压覆盖程序文件，保留 `data` 文件夹。
- 退出后复制整个文件夹即可备份或换电脑。密钥库由主密码加密，换电脑后输入主密码即可解锁；模型 API Key、云服务连接凭据、图床密钥和 Linux.do 登录由 Windows 系统加密，换电脑或换 Windows 账户后需要重新填写。如需连同这些凭据一起迁移，使用「设置 → 数据 → 创建加密备份」并勾选「同时包含系统保护的凭据」，见[备份与恢复](#备份与恢复)。
- 从安装版迁移：退出两个版本，把 `%APPDATA%\Nanpad` 的内容复制到便携版的 `data` 文件夹。
- 便携版不写入注册表，不创建开始菜单项，也不注册网页采集协议；删除文件夹即可完全移除。

## 浏览器密码与文档助手

「密钥库 → 浏览器密码」可与 Chrome / Edge 双向迁移密码 CSV，预览不显示密码，重复与冲突分别提示。同一网站的多个账号独立保存；导入冲突默认跳过，避免覆盖已有密码。配套浏览器插件自动建议本站账号，选择后填写；登录采集和网页文档保存只需一次确认。详细步骤、浏览器设置地址及功能边界见[浏览器助手教程](BROWSER-EXTENSION.md)。

浏览器导出和知屿导出的 CSV 都包含明文密码，导入完成后删除文件。插件不会直接读取浏览器原生密码库。登录填写仍需你选择账号并提交；文档保存的是当前已加载、可读取的正文快照与来源，不会绕过文档权限，也不是原生文档持续同步。

## 调整文字与界面大小

在「设置 → 外观 → 界面大小」选择 100%、110%、125% 或 150%；软件保存该选择。「恢复默认大小」或 `Ctrl / ⌘ + 0` 恢复 100%，`Ctrl / ⌘ + 加减号` 逐档调整。此设置改变应用内文字和控件大小，不更改 Windows 显示缩放。

本版使用系统字体，并移除弹窗稳定状态下多余的模糊和合成效果。若仍感觉发虚，记录屏幕分辨率、系统缩放、应用界面大小，以及是整窗还是某个区域不清楚；多显示器环境分别比较。不同显卡驱动、远程桌面和系统兼容性设置仍需按实际环境排查。

## 添加主机

1. 进入主机分类，点击新增，先填写「主机名」与「IP / Host」。
2. 选择「仅记录」即可先保存资产。尚未获得真实指标时显示「未采集」；保存地址不代表 SSH 已连接。
3. 需要连接时选择「配置 SSH」，填写端口、用户名及密码、私钥或 SSH Agent。凭据保存前需要解锁密钥库；测试连接后再保存。
4. 地区、系统、状态、标签等信息在高级选项中维护。编辑已有主机时，不展开高级选项或切回「仅记录」不会清空原有 SSH 凭据。
5. 保存后在详情中刷新实际指标，或打开 SSH 终端、SFTP。连接失败时核对地址、端口、防火墙和登录权限；这些操作会连接真实服务器。

在「设置 → 监控采集 → 服务器自动采集」选择「仅手动刷新」或每 1、5、15、30、60 分钟采集，默认每 5 分钟。自动采集只在窗口可见且密钥库解锁时进行；仅有资产记录、没有 SSH 配置的主机不会因此变成可连接状态。手动刷新仍可主动获取最新指标。

本机连不上的主机（例如需要代理、只在公司内网），关掉主机卡片右下角的「采集」开关：之后不再连接、不计入「需要留意」、不弹离线通知，上次采到的数据保留并淡显；需要时再打开即可。本机 AI 用量监控独立运行，不受服务器采集周期影响。

## 记录在线服务

进入「服务资产」添加 Cloudflare Workers、个人博客、自建邮箱服务或其他服务，填写名称，可选填写服务网址、提供方、标签与说明。状态由你手动维护，保存不会自动探测服务，也不会创建或部署远端资源。

服务资产可在卡片、表格和关系图中查看，并与账号、服务器、域名及文档关联。登录凭据保存在密钥库，再通过关联连接到服务；不要把密码放入服务网址或普通说明。Agent 可查询服务元信息和已有关系，不能据手动状态断言服务刚刚通过在线检查。

## 文档、图片与服务器运维记录

进入「文档资产」可新建独立文档，也可以从「服务器详情 → 服务文档」新建已关联的文档。两处使用同一编辑器和自动保存流程，不需要维护两份资料。右侧「关联资产」可绑定多项资产，取消关联不会删除文档。

「导入 Markdown」：点击文档列表上方「＋ → 导入 Markdown」，多选 `.md` / `.markdown` 文件；也可在任意页面将文件拖入窗口，松开后导入并打开文档资产。一次最多 50 篇，每篇最多 1 MiB；支持 UTF-8，以及带 BOM 的 UTF-16 中文文件。导入后以文件名作为标题，直接进入阅读模式，也可点击「编辑文档」继续修改和关联资产。同名文件会生成独立文档，不覆盖现有内容；每篇分别保存，失败文件及原因在导入结果中查看。只拖入图片时仍由文档编辑器处理，不触发 Markdown 导入。

导入后保留 Markdown 源码，阅读时按 Markdown / GFM 排版，支持表格、任务列表和代码块。原始 HTML 不执行，远程图片不会自动下载，也不会读取文件旁边的本地图片。未支持的语法继续保留在源码中，显示效果以预览为准。

点击「编辑文档」后可切换「Markdown 源码」「预览」与「富文本」。源码修改自动保存，导出 Markdown 时保留当前源码；仅查看富文本文档的源码或预览不会修改原文。确认修改源码后，该文档以 Markdown 保存，富文本专属格式可能变化。将 Markdown 转为富文本会先提示表格、脚注和源码排版可能变化，可以先导出留存，或选择「保留 Markdown」取消转换。

已有文档默认进入阅读模式，正文和标题不可编辑，也不显示格式工具。点击「编辑文档」后修改标题、正文或插入图片；新建文档直接进入编辑模式。「完成编辑」会等待保存成功再返回阅读，失败时保留编辑状态和草稿。

阅读区底部显示当前章节与阅读进度，点击「目录」查看标题并定位；右侧按钮可「回到顶部」和「前往底部」。收起文档列表后，导航仍保留。目录根据正文标题生成；没有标题时会提示添加标题，重复标题仍可分别定位。

标题和正文修改后自动保存。查看「已保存／保存中」状态；保存失败时内容留在编辑器中，可点击保存重试。桌面端保存到本机，网页预览保存到当前浏览器，二者不是自动同步的数据空间。

点击「插入图片」，也可直接粘贴截图或拖入照片。图片入口旁会显示保存位置：未开启图床时嵌入本地文档，开启后上传到自己的图床并保存图片地址。失败时点击「重试未完成的图片」，已经插入的图片继续保留，不重复插入。删除图片仅删除文档引用，不删除图床里的文件。

「图片设置与已有图片迁移」内可以配置图床、切换新图片保存方式，或主动将原有内嵌图片上传到图床。开启图床不会自动上传以前的图片。迁移中断后已成功的部分保留，可继续重试。支持 PNG、JPEG、WebP，单次最多 20 张、原文件每张不超过 8 MiB；图片会在本机缩放后再保存或上传。

旧版服务器 Markdown 仍保留在「服务文档」页，可只读预览、复制或导出。点击「迁移并编辑旧文档」后，完整 Markdown 原文作为代码块保存到统一文档，不自动转换为富文本；代码、链接文字和换行保留。旧记录不会被清理，失败也不会删除原文。重复点击只打开已迁移的同一篇文档，不覆盖新编辑的标题、正文或解绑结果。运维模板会新建文档，不覆盖当前资料。

## 自建节点与流量来源

1. 在「自建节点」或服务器详情中添加／导入节点，保存后继续配置流量来源，也可稍后从「用量记录」进入。
2. 选择 3x-ui 或机场订阅。3x-ui 填登录页根地址（包含自己的自定义路径）、面板用户名和密码；入站 ID、客户端 Email 等条件放在可选的高级筛选中。不要把 `/panel/inbounds` 当作登录根地址。
3. 机场填写订阅地址。来源与节点关联用于标记归属，不代表该来源的全部流量都由这个节点产生。
4. 点击「保存并验证连接」。界面分别显示来源已保存、验证成功或连接失败；首次验证由本次点击触发，失败仍保留来源，可检查信息后重试。
5. 后续刷新或采集失败时，上次数据会保留并显示错误，不能把它当作本次实时值。来源没有提供的流量无法凭节点地址补算。

在「用量记录 → 订阅与来源」管理已有连接。点击页头「连接用量来源」打开新增弹窗；卡片上的编辑按钮可修改名称、连接信息和关联节点。编辑时不回显订阅地址、用户名、密码或 API Key，留空保留原值，保存后重新验证；来源类型不能修改。移除前需要确认和解锁，移除后停止更新并删除该来源的连接凭据，历史用量保留。

同一规范化订阅地址重复添加会复用已有机场来源；名称相同但地址不同的来源保持独立。编辑时换成另一个已存在的订阅地址会被拒绝，需使用已有卡片。更换地址后保留旧历史、清除旧节点缓存，并从新地址的首次采样重新建立流量基线，不把新旧累计值的差额计作新增流量。

机场卡片按服务商返回值展示「机场累计已用」「剩余流量」「总额度」与到期时间；缺失字段显示未提供，服务商返回总额为 0 时显示不限额。节点列表与流量头分别解析，能读取节点不代表服务商提供了流量。展开「节点详情」读取最近一次缓存，可搜索名称、协议或主机；展开、收起和搜索不会重新下载订阅，更新节点需点击卡片刷新。

节点摘要支持 URI、Base64、Clash 和 sing-box 订阅，正文超过 2 MiB 会拒绝读取，最多展示前 1000 个可识别节点。订阅地址加密保存在密钥库，普通缓存只保留节点名称、协议、主机、端口等展示信息，不保留节点认证参数或原始订阅正文。机场总用量不能分摊为每个节点的计费用量。

3x-ui 的登录权限和 API Token 用量的组织权限是不同问题。面板错误应核对登录地址、账号及返回信息；OpenAI / Anthropic 用量接口一般需要有组织查询权限的 Admin Key，普通推理 Key 经常没有权限。不要为解决 API 用量的 403 去修改 3x-ui 权限。

### 查看 v2rayN 本机流量

在机场卡片中展开「节点详情」，下方的「v2rayN 本机流量」读取本机客户端统计。Windows 会自动查找 v2rayN；未找到时点击「选择目录」，选择含客户端配置的目录。此读取无需管理员权限或解锁密钥库，不修改代理设置、节点配置或客户端数据库。

- **客户端已保存统计**：显示节点的已保存累计和今日已保存上传／下载，按 v2rayN 的 KB 口径、1024 进位显示。客户端通常在退出时保存统计，因此这不是实时值；未保存的数值显示未提供，旧日期的记录不会当作今日用量。
- **当前核心实时统计**：只读取 Xray 已启用且监听本机回环地址的指标接口，展示以字节计量的「本次核心累计」和「本次监测增量」。面板进入可视区域且页面可见时约每 5 秒读取；监测开始、节点切换或核心重置后重新建立基线。该增量仅覆盖本次观测，不是全天或完整会话历史。
- **节点归属**：按地址、端口和协议匹配；相同目标存在多份配置时还需名称唯一对应。无法确认归属时不将实时值计入当前机场，可切换「全部客户端节点」查看当前核心出口。

未开启可用的实时接口，或当前核心不支持该接口时，会显示「实时接口不可用」，仍可查看已保存统计。知屿不会替你启用 v2rayN 的统计功能或开放接口。客户端未保存统计、配置不可读与实时接口不可用是不同状态，按界面提示处理。

这些数值只描述本机客户端记录和当前核心出口，不是机场的逐节点账单，也不包括其他设备的全部流量。已保存统计、实时字节与机场总量分别展示，不相加。

## 用量明细与本机 AI 监控

「用量记录」包含「用量概览」和「订阅与来源」两个标签页。「用量概览」按流量增量、API Token、本机 Token、订阅额度分开显示。点击统计卡或通过类型、来源、时间、模型下拉框筛选，展开记录查看输入、输出、缓存、流量增量或额度窗口；每页显示 20 条，导出包含当前筛选的全部记录。

用量趋势图按日期展示输入与输出 Token、上传与下载增量；构成图可按来源或模型比较。日期与来源用于统计、图表和明细，模型只筛选 Token，不影响流量和额度。来源候选随类型变化，模型候选随类型和来源变化，不适用的选择会自动清除。同名来源增加类型与标识区分，已移除来源仍可查看历史并标注「已移除」。订阅额度按具体来源和窗口查看快照，不把多个窗口相加；图表下方可展开数据表核对数值。

当前筛选包含今天且有记录时，趋势图下方直接显示今日输入、输出明细。某天的用量远小于历史峰值时，会在真实数值位置显示小圆点，柱高不会人为放大；没有记录的日期不补零。悬停提示和数据表可核对完整数值。

点击页头「采集与监控」查看各客户端状态、开启或关闭本机监控；这些配置在侧面详情中展开。关闭详情后继续查看原有图表与明细，「查看全部本机历史」会关闭详情并切换统计筛选。

本机监控默认开启，无需解锁密钥库；如果之前主动关闭过，可点击「开启本机监控」，软件会记住开关选择。应用运行时，每约 10 秒增量读取 Codex、Claude Code、Grok Build、Gemini CLI 标准本地日志。支持 Windows 将可信客户端根目录映射到其他磁盘的情况，根目录内的任意链接仍不会跟随。它不要求请求经过知屿代理，但只覆盖客户端确实写入日志的用量，不能读取所有 AI 软件或网页聊天的 Token；首次历史导入会分批完成。

每个客户端分别显示查找、导入、正常采集、没有 Token 记录或采集受阻，并展示最近一次真实用量的日期。「查看全部本机历史」切换到本机类型和全部日期；已经找到旧日志但最近 30 天为零时，可用它核对历史。已安装或使用过网页服务，并不意味着本机存在包含 Token 的 CLI 会话日志。

采集器仅保存用量数字、模型、日期和匿名会话标识，不保存对话正文、凭据、完整日志路径，也不上传日志。本机 Token 与组织 API 账单可能重叠，不合并成一个总量；订阅百分比不换算为 Token。流量首次采集和计数重置不产生可确认增量，历史流量无法凭当前累计值倒推。

点击「关闭本机监控」停止后续采集，已经保存的统计保留。锁库不暂停本机用量采集；电脑休眠期间不会采集，唤醒后继续。需要账号凭据的远程 API、邮箱等功能仍需解锁。目录不可读、损坏记录或采集限额会显示状态，不能把“未发现日志”当作零用量。

切换页面会先显示已有用量快照，10 秒内复用同一次界面读取；读取统计不会额外触发远程采集。自动远程用量采集复用最近 5 分钟的成功结果或失败状态，自动主机检查在所选采集周期内复用结果；手动刷新仍会请求最新数据，失败时保留上次数据及错误。文档保存、删除和批量导入只更新受影响条目的缓存，不重新读取整个列表；收到不含变更详情的旧式通知时才重新读取列表。检索索引在资产或知识文件变化后更新，避免每次打开页面或提问都重建。上述时间是缓存有效期，不表示每个来源都有相同的后台采集间隔。

本机采集完成后会通知页面，新统计写入后图表、卡片和明细随之更新；只有采集状态变化时复用已有统计，不重新加载整份数据。约 10 秒是扫描间隔，客户端尚未写入日志的 Token 仍无法提前读到；软件关闭、休眠或日志不可读时也不代表正在实时采集。

## 每日活动

「资产总览」中的每日活动展示近 14 天活跃分布，可点击日期或用下拉框按日期、资产类别筛选，逐页查看操作记录。最多保留最近 90 天的 3,000 条。查看资产详情、保存修改、手动检查会记录活动；后台自动刷新不会伪造活跃记录。新增查看记录只保存资产类别，不附带资产名称、网址或凭据。

## 域名、邮箱与证书

域名填可查询的域名名称并刷新；到期信息受 WHOIS 服务可用性影响。证书填实际 TLS 主机，查询签发者、有效期和信任状态。邮箱使用服务商的 IMAP 授权码或配置方式，网页身份授权与邮箱 IMAP 密码不是同一项能力。

## 快速开始与订阅模板

首页的「快速开始」列出五步：添加第一项资产、记录费用与续费日、写一篇运维文档、关联两项资产、用标签分组。每一步按已有资料自动打勾，点击直接跳到对应页面；不需要时点「不再显示」。下方「近期续费」列出未来 14 天要到期或按周期续费的事项。

新建资产窗口下方有「从常用订阅开始」：选 ChatGPT Plus、Claude Pro、Cloudflare Workers、iCloud+、Netflix 等模板，名称、金额、周期和下次续费日都已填好，保存前可以修改；价格只是常见标准价，以实际账单为准。AI 工具类模板直接进入 AI 订阅的手动表单，其余作为服务资产保存。

按 `?` 打开键盘快捷键一览，头像菜单里也有入口。`Ctrl K` 的「操作」分组可以直接切换深浅色、打开订阅模板、续费日历和系统设置。

## 自定义资产类型

内置类型放不下的东西，可以自己定义类型：点「新建资产」，在窗口里的「自定义资产」分区点「新建自定义类型」（`Ctrl K` 搜「自定义」也行），填写类型名称、选一个图标，再添加最多 12 个字段，字段类型有文本、链接、日期和数字；保存后直接进入添加表单。之后在同一分区点类型卡片就能添加这一类资产，修改和删除类型在「服务资产」页的「管理类型」。保存后，「添加服务」里的「资产类型」下拉会出现这个类型，选中后填写它的字段；类型里也可以直接选「＋ 新建自定义类型…」。

自定义类型的资产本质上是服务资产，所以费用、到期日、续费日历与「已续费」、标签、关联、备份和 AI 助手都照常可用。服务资产页上方的类型按钮可以只看某一类；卡片和详情页显示字段，链接字段可点击打开。删除类型不会删除资产，它们回到「其他服务」，字段值一并清除。字段内容和资产一样明文保存在本机，不要填写密码或密钥，凭据请放进密钥库。

## 资产详情与系统设置

点击资产卡片、表格行、关系图节点或搜索结果，详情在主内容区打开：左列是资产本身与监控指标，右列是关联资产、文档和凭据位置。标题栏面包屑显示所在分类和资产名，点击分类名即可回到列表。顶部「返回」、标题栏后退、Alt+←、鼠标侧键或 Esc 都会回到原列表，筛选条件和滚动位置保持不变。

头像菜单中的「系统设置…」和「个人资料」以页面打开，左侧是分组导航；右上角的设置按钮和 Ctrl+, 打开的是设置弹窗，所有分页使用同一尺寸。两者内容相同，按习惯选用即可。

## 备忘提醒

不属于任何资产、但又要按时处理的事（宽带续费、车险、证件到期、信用卡还款……），在「费用与续费」页的「备忘提醒」里点「新建提醒」，填写提醒什么、日期、是否重复（每周 / 每月 / 每年）和提前几天提醒。卡片上的大号数字是倒计时：还剩几天、今天，或已过期几天。

处理完点 ✓：不重复的标为已完成（可在「已完成」里恢复或删除），重复的自动顺延到下一期，提示里可以撤销。首页「近期续费」会把 14 天内的提醒和资产续费放在一起。

桌面版到了提前天数会弹系统通知；在「设置 → 邮件推送」勾选「续费与备忘提醒也推送到这个渠道」后，同样的提醒会推送到 Telegram、Server酱 / 微信、企业微信或 WxPusher（只含名称和天数，需要桌面版运行且密钥库已解锁）。资产到期前多少天开始提醒，在「设置 → 后台运行」里调整。网页版在页面打开时用浏览器通知提醒；在网页版「设置 → 提醒推送」配置渠道后，服务器每小时检查一次并推送，浏览器关着也能收到。

## 网页版（自托管）

想在家和公司都能用、又不想在公司电脑上安装，可以把网页版部署到自己的服务器上，见 [网页版部署说明](WEB.md)。网页版与桌面版共用界面，资料存在服务器上，密钥库在浏览器里加密；可以把桌面版的加密备份恢复到网页版，也能从网页版下载备份到桌面版恢复。

## 费用与续费

在服务器、域名、服务资产和号码中填写费用与到期日后，「费用与续费」页按月、按年折算支出。「续费日历」以月视图列出每天的到期资产，颜色区分资产类型；月付、年付的资产会按周期推算后续续费日，以空心标记显示。点任一天，右侧列出当天事项，点击进入资产详情。下方「到期时间线」列出未来 30 或 90 天的到期项目，可导出 ICS 日历。

续费完成后，在时间线、日历当天列表或首页「近期续费」点「已续费」，到期日按月付或年付顺延一期，日历和提醒随之更新；提示里的「撤销」可以恢复原日期。按周期推算的日期、一次性费用和网页授权同步的 AI 订阅不显示这个按钮。时间线右上角的「让 AI 规划」会带着当前 30 / 90 天范围进入 AI 助手，询问续费顺序、合计金额和缺少费用的资产。

## 组织资产

资产支持多个标签。搜索与标签可以组合使用；卡片适合浏览、表格适合排序比较、关系图适合看连接。详情中建立关联后，两端都能跳转。需要留意的事项可导出 ICS，导入常用日历。

在服务器等资产分类页，通过卡片／表格旁的「关系图」按钮切换显示方式；图中会带出与当前资产相连的其他类型，方便查看完整组合。需要查看全部资源时，进入左侧「标签」，选择「关系图」后点击「全部资源」，未绑定文档也会显示。实线表示已保存的资产关联，虚线表示已保存的文档绑定，点击节点可打开对应资料；同名或共同标签不会直接变成关系。

点击「管理资源关联」，在「新增关联」选择两项资源并保存；在「已确认关联」中可解除关联，资料本身继续保留。「发现关联」根据相同主机地址、非通用的共同标签或文档标题完整提及资产名称给出本机建议，显示匹配依据，勾选确认后才写入。此匹配不读取账号凭据或文档正文，也不请求模型。当前不支持文档与文档直接连线，可以把多篇文档绑定到共同账号或服务器。画布最多显示 300 项资源，超过时需要缩小筛选范围。

## 保存网站注册账号

需要独立保存 Apple ID 等资料时，进入「密钥 → 添加账号」。填写显示名称、账户名、密码，可选填写登录网址和敏感备注；账户名、密码、网址与敏感备注保存到加密密钥库，普通资产数据只保留名称、类型、分组和标签等元信息。此入口需要桌面版，网页版不会将账号凭据写入本地存储。编辑时留空密码会保留原密码；锁库会清空未保存的敏感表单内容。

点击账号整行即可打开详情，不必先进入设置。锁定时点击详情中的「解锁查看」，输入主密码后在原处查看；编辑入口用于修改账号信息，密码仍默认遮挡。侧栏底部也可随时解锁或主动锁定。

账号详情中的「关联已有文档」可绑定注册说明、订阅凭证或使用笔记，也可直接新建资料文档。在文档的「关联与设置」中，可从已关联条目打开对应资产。关联只保存引用，密码不会复制到文档；密码和恢复码应放在加密敏感备注中。解除关联不会删除文档。删除独立账号需要确认和解锁，会移除其加密凭据，文档本身保留。

邮箱文件夹和密钥分组使用统一的收纳卡片，显示数量及内容预览；点击卡片进入，右下角可直接编辑名称和颜色。原有网站账号入口仍可使用：

1. 进入「密钥」，点击「添加资产」，将「类型」切换为「网站账号 / 密码」。
2. 填写站点名称，也可以点击「智能粘贴」后输入登录网址，点击识别结果自动填入。网址中的用户名、密码、查询参数和片段会被移除；需要特殊登录路径时可以自行核对登录地址。
3. 解锁密钥库，填写「登录地址」「账号」「密码」。恢复码、二次验证备用码放在加密账号备注中，不要填进普通资产说明或提示。
4. 点击「添加」。取消解锁或凭据保存失败时，表单会保留，资产不会被当作已成功保存。
5. 打开网站资产详情，在「选择关联资产」中选择已保存的邮箱，再点击「添加关联」。关联是双向的，可以从邮箱记录返回网站。
6. 下次打开详情即可查看登录地址和账号；密码默认遮挡，解锁后按需显示或复制。锁库后这些账号字段隐藏，JSON 资产导出不带出加密账号信息。

普通名称、提示、标签和说明没有整体加密，不要把密码写进这些字段。

### 网站动态验证码

在账号详情展开「动态验证码」，点击「添加动态验证码」，粘贴网站提供的 Base32 验证器密钥或 `otpauth://totp` 链接并保存。密钥加密保存在本机，详情显示当前验证码和剩余秒数，可直接复制；锁库后隐藏验证码并停止读取。

直接粘贴 Base32 密钥时使用 SHA1、6 位、30 秒周期；链接可指定 SHA1、SHA256、SHA512，6 位或 8 位，以及 15–120 秒周期。不支持 HOTP 计数器链接、短信接码或推送确认。验证码取决于本机时钟，网站拒绝时先核对系统时间与网站配置。删除本机配置不会关闭网站的两步验证，应保留网站提供的恢复方式。

### Linux.do 身份与本人帖子

Linux.do 用于绑定当前工作区的主身份，入口在首次设置和「设置 → 个人资料」，不再从密钥库新建身份资产。普通用户使用知屿统一登录服务，无需配置应用密钥。登录、头像与昵称同步、更换账号和退出的详细步骤见[主身份与个人资料](MAIN-IDENTITY.md)。

1. 在「Linux.do 主身份」点击「使用 Linux.do 登录」，在系统浏览器完成官方授权，回到知屿核对用户名、平台返回邮箱与信任等级，选择是否同步昵称、头像，再点击「确认绑定主身份」。登录服务尚未就绪时，可先完成本机设置，稍后回来绑定。
2. 在已登录的个人资料中点击「加载我的帖子」，按需「加载更多帖子」。列表包含本人公开主题与回复的摘要，每页最多 30 条、当前列表最多 200 条；已取得条数不代表总发帖数。缓存有效期 15 分钟，手动「刷新帖子」可重新请求。
3. 勾选 1–20 条，点击「保存所选全文」。主进程核对作者与帖子编号，将成功项的全文、标题和来源保存为一篇新文档。优先保留平台返回的 Markdown，只有 HTML 正文时转为纯文本；不下载图片。失败项单独列出，可点击「重试未导入的帖子」。
4. 点击「打开已保存文档」，再按需使用文档里的「提取账号」，检查后确认加密入库。主身份本身不是密钥库账号资产，不会自动创建虚构的账号关联；文档可另外关联已有资产。

Connect 身份授权与论坛帖子访问是两项能力。当前帖子接口只读取公开可访问内容，不读取私信、受限主题或浏览器 Cookie；遇到 HTTP 403、限流或正文缺失会显示实际失败并保留已有缓存，不以摘要冒充全文。单帖正文超过 256 KiB 时需打开原帖或手动导入。已保存文档是本机副本，不持续同步线上编辑，再次导入不会覆盖之前的本机修改。

退出 Linux.do 登录后保留身份资料、同步偏好及已保存文档，清除本机登录凭据与帖子缓存；刷新资料或读取帖子需要重新登录。旧版从密钥库导入的身份资产和文档关联继续保留，不会自动迁移为主身份，也不会因本次绑定或退出被删除。

### 从文档提取账号

打开文档，点击「提取账号」；Linux.do 帖子保存后也可打开该文档再使用此入口。知屿在本机识别明确的「网址、账号、密码、备注」字段及 Markdown 表格列，不调用远端模型、不猜测叙述中的密码。文档最多 1 MiB，一次最多识别 50 个候选。

逐项核对名称、网址、账号、密码和备注，可修正字段并勾选要保存的记录，再点击「保存并关联」。确认后将凭据加密存入密钥库，并把账号关联到来源文档；相同站点、用户名和密码复用已有记录，不同密码保留独立记录。预览 5 分钟后失效；锁库、取消或文档已修改时需重新提取。保存结果会区分账号已存与文档关联失败，关联失败可重新提取确认补全。

提取不会修改或清除原文中的账号密码。来源文档仍是普通本机资料，导出或允许 AI 读取正文前应先检查并移除不应共享的敏感副本；存入密钥库不会自动保护文档里的那一份。

### 从浏览器保存账号

1. 安装同一版本的 [浏览器插件](BROWSER-EXTENSION.md)，打开知屿「设置 → 浏览器插件」，点击「生成配对码」，按提示解锁密钥库。
2. 将配对码复制到插件的配对输入框并连接。配对码只能使用一次，5 分钟后失效；主密码只在桌面端输入。
3. 在网站提交登录表单后，页面会出现保存提示，核对账号后点击「加密保存账号」。也可打开插件，重新读取当前可见表单，核对后点击「加密保存到知屿」；无法识别时手动填写。
4. 等待插件显示保存结果。1.3.1 插件一次确认后直接写入主密码库，同站不同账号分别保存；相同账号同密码去重，不同密码保留原记录并新增版本。回到密钥库后可分组或关联邮箱、文档，无需再次录入凭据。
5. 提交采集的待确认凭据仅在扩展后台短期内存保留，最多 2 分钟；后台休眠或关闭标签页可能提前清除。提示过期时需重新读取当前表单，插件不能从已清空的页面恢复旧密码。锁库、桌面退出或浏览器会话结束后需要重新配对。

已保存账号会在相同站点的登录页自动建议，选择一个账号后填写，仍由你点击网站登录按钮。匹配严格区分协议、域名和端口，不自动扩展到子域名；不向普通 HTTP 网站、注册/改密表单、隐藏字段或 iframe 填写。

在插件里可分别关闭登录采集、账号建议和文档提示。插件不读取浏览器自身保存的密码、Cookie 或历史记录。只想记录网址时可选择「仅记录站点并打开知屿」；旧版插件的桌面待确认队列仅作为兼容入口。完整安装步骤、网页限制与连接排错见 [浏览器助手教程](BROWSER-EXTENSION.md)。

### 保存网页文档

腾讯文档、微信公众号文章、飞书、语雀等受支持页面会显示「留一份文档到知屿」。点击「保存当前文档」后，在桌面「文档资产」查看快照并关联账号或其他资料；普通网页也可从插件主动保存。没有可读正文时保存来源链接，重复保存同一来源返回已有文档，保留本机编辑。

只读取当前页面已经加载的可见文字，不读取未加载分页、画布或跨域内容。正文保存为本机普通文档，不属于加密密码库；不要把密码或恢复码保存在文档中。

### 批量整理与关联

1. 在资产列表顶部点击「批量整理」，按名称或类型搜索，勾选需要修改的资产。「选择搜索结果」只影响本次搜索显示的条目，隐藏的已选条目仍保留。
2. 标签模式可添加或移除逗号分隔的标签，已有标签不会重复；未选中的资产不受影响。
3. 关联模式选择目标资产，将选中的资产一次关联过去。自关联、重复关系及已删除资产的引用会被过滤。
4. 详情中的「搜索与多选关联」支持一次添加多条关系，已有关系可逐条解除。
5. 关系图点击「连接资产」开启连线模式，从一个节点的出口拖到另一个节点的入口建立关系；关闭该模式后恢复普通浏览。

## 检查收件箱

1. 使用邮箱「快捷登录」验证 IMAP 账号并保存，或在邮箱资产中录入加密的用户名及密码 / 授权码。
2. 打开邮箱详情，在「IMAP 连接设置」中核对服务器和 TLS 端口，常见端口为 993，点击「保存连接设置」。只有 TLS 连接受到支持。
3. 保持密钥库解锁，点击「检查新邮件」。显示收件箱总数、未读邮件、本次新增和上次检查时间；容量只在服务器提供时更新。
4. 首次检查、服务器重置 UID 状态或更换连接配置时，先建立基线，新增显示为未知，不代表没有新邮件。后续检查按 UID 统计新增邮件；未读邮件可能是很早以前收到的，两者不能等同。

「检查新邮件」和自动提醒只读取数量与 UID，不下载邮件正文、不自动标记已读。独立邮件阅读区会在你主动打开时读取标题、正文，并支持附件下载与 SMTP 发信，配置见 [邮件工作台教程](MAIL-WORKSPACE.md)。需要服务商允许 IMAP / SMTP 访问；部分邮箱要求客户端授权码。Google/Microsoft 网页身份授权并不等于本版 IMAP / SMTP 密码登录凭据，禁用基本身份验证的服务可能无法连接。演示邮箱不连接真实服务。

### 整理邮箱与阅读正文

邮箱首页先显示工作、生活及自定义文件夹，进入分组才展开账号；搜索可以匹配分组名称。点击账号头像，在「邮箱头像与分组」中上传图片或修改归属，保存后生效。选中多个账号可批量移动，删除分组只把账号放回未分组，不删除邮件。

点击邮箱地址打开阅读器。正文默认以安全 HTML 或 Markdown / GFM 排版显示，可切换「原文」查看解析后的纯文本。列表与正文分别显示加载占位，窄窗口通过「返回列表」切换。阅读不会自动标记已读，需要点击「标为已读／未读」。

正文的远程图片默认拦截；点击「加载本封图片」后，图片服务器可能得知你的 IP 地址和阅读时间。授权按邮件记忆，最多保留 500 封，可在「设置 → 存储」清除；「隐藏外部图片」不能撤回已完成的请求。符合限制的 CID 内嵌图片直接在本机显示。

点击正文上方的发件人头像，可上传本地图片，每个收信账号最多保存 32 个。没有图片时显示已保存的同地址邮箱头像或首字母，不会自动到外部网站查头像。头像与地址对应关系保存在明文资产记录中，不进入自动 RAG 索引。

## 设置邮件推送

1. 进入「设置 → 邮件推送」，解锁密钥库。
2. 在「推送渠道」选择 Telegram、Server酱 / 微信、企业微信群机器人或 WxPusher。Telegram 填写自己的 Bot Token 和 Chat ID；Server酱填写自己的 SendKey；企业微信填写群机器人的 Key；WxPusher 填写自己应用的 AppToken 和以 `UID_` 开头的接收用户 UID。
3. 勾选要检查的真实邮箱，设置 5 至 1440 分钟的检查间隔，再勾选「启用自动邮件推送」并保存。每个邮箱应先完成 IMAP 设置和手动检查。
4. 点击「发送测试消息」验证渠道。这一步会向所选目标发送真实测试消息；未保存更改时该按钮不可用。
5. 保持桌面端运行及密钥库解锁。首次自动检查仅建立基线，后续发现新增邮件才发送提醒；关闭软件或锁库会停止新的检查和推送。

通知只发送新增数量、相关邮箱未读数量和检查时间，不发送邮箱地址、邮件标题、正文、授权码或密码。检查失败不会被当作零未读；网络失败保留待发送提醒供后续重试，不能保证第三方服务在所有网络情况下恰好接收一次。更换推送渠道、Telegram 目标或 WxPusher UID 后需要确认并重新配置凭据。个人微信通过 Server酱或 WxPusher 接收通知，不是直接登录或操作个人微信。

## 设置头像与资产图片

个人头像在「设置 → 个人资料」中上传。资产图片在新增或编辑表单中上传；通过快速登录添加的 AI 订阅，打开详情后点击编辑即可补充图片。选择文件后先查看预览，再保存表单。已有图片可以更换，也可以点击移除图标并保存，恢复默认显示。

邮箱账号及发件人头像也可直接从邮件工作台中的头像按钮编辑，使用头像的 256 像素处理规则。账号头像随邮箱资产保存，发件人自定义图片只用于当前收信账号；详细数量和大小限制见 [邮件工作台教程](MAIL-WORKSPACE.md#发件人头像)。

仅支持本地 PNG、JPEG、WebP 文件，单张不超过 8 MiB，最长边不超过 8192 像素，总像素不超过 2400 万。头像会缩至最长边 256 像素，资产图片缩至 512 像素，再重编码为 PNG；单张持久化图片不超过 1 MiB。未启用图床时处理和存储在本机完成；文档和资产封面启用图床后会上传到配置的服务。个人头像仍在本机保存。不能直接填入任意远程图片链接，也不支持 SVG。

## 连接模型

进入「设置 → 模型与知识库」。选择服务商预设或编辑 API Base URL，填写 API Key 与模型名。点击「读取模型」获取服务端支持列表，点击「测试连接」确认真实推理返回。

Base URL 必须属于提供 Key 的服务。切换地址后旧 Key 关联会被清除，需要重新填写。模型必须支持 OpenAI Chat Completions 和工具调用；只支持其他协议的接口需要服务商提供兼容网关。

## 导入知识与问答

在模型设置中导入 TXT 或 Markdown，单文件不超过 500 KB。返回问答页面发送问题，可查看检索和工具阶段，也可停止生成。回答中的标题、列表、表格、代码块按 Markdown 展示，展开「检索来源」查看依据并跳转资产。

不要把主密码、私钥或服务 Token 放入文档和提问。自动索引会排除资产凭据字段，但用户主动输入的文字不会自动变成保密字段。

询问「某个网站账号的密码保存在哪里」时，回答可提供「打开凭据位置」入口。点击后进入对应资产详情，在本机解锁查看；定位成功不代表已经保存了密码，也不意味着密码曾发给模型。

询问「我有哪些邮箱分组」「工作邮箱里有哪些账号」时，Agent 可以查询本机分组目录、空组、未分组和账号归属，并区分邮箱、别名及演示记录。这项查询不连接 IMAP，不需要开启实时邮箱许可；分组名称、邮箱地址及归属会作为元信息发给配置的模型，头像、密码、正文和草稿不会随工具结果发送。调整分组后，下一次问答读取更新后的记录。

询问「我的邮箱是否有新邮件」时，发送前勾选「本次允许查询邮箱」。许可仅对这次问答有效，下次发送默认关闭；没有许可时模型只能基于已有记录回答，不会自行连接邮箱。实时查询需要已保存的真实邮箱、有效 IMAP 配置和解锁的密钥库，传给模型的结果仅有数量及时间。勾选不会授权模型发邮件、读取正文或发送通知。

错误回答下可以点击「重试这条问题」，使用当前模型设置和当前勾选的本次权限重新发送原问题；旧问题不会在对话中重复添加，也不会自动恢复上次正文或邮箱授权。「检查模型设置」可直接调整连接。鉴权失败仍需核对服务地址、有效 API Key 与模型名，重试不能代替正确配置。

内置能力入口可填入文档改名、修改正文、整理账号和发现关联的问题。发送前可勾选「本次生成修改建议」；如果缺少所需权限，回答下方的「继续完成这项任务」会说明用途，点击对应的「允许本次……并继续」按原问题继续，无需复制正文或重复输入。权限仅本次有效，下一条问题不会自动继承。模型返回建议后会展示依据、修改前后内容；点击「确认应用这项修改」才写入，或点「忽略」保留原内容。当前范围：

- 文档标题：例如「把《测试指南》改名为《服务器信息概要》」。先检索目标与原标题，再生成重命名建议；无需读取正文，确认后保留正文、格式与关联。
- 文档正文：需要允许本次读取正文和生成修改建议。在一个文本节点中唯一匹配的局部替换，保留其余内容与格式；跨段落、跨格式节点或多处重复的片段需缩小后再生成。
- 账号：修改普通名称与标签。用户名、登录网址、密码及敏感备注仍需在本机账号面板编辑，模型不读取或修改密钥库。
- 关联：在两项资产之间建立关联，或把文档绑定到资产。确认前仅为建议，不能当作已保存关系。

- 资产资料：补齐服务器、域名、服务资产的费用与到期日，AI 订阅的续费日与月费，以及标签和备注。主机地址、账号和凭据不在修改范围内。
- 新建文档：起草运维手册、巡检清单或续费计划，可关联最多 10 项资产；不确定的步骤以待办标出，不写入密码或密钥。

每个回答下方的「下一步」给出 2 至 4 个按钮：追问类会直接发送新问题，打开类会跳到续费日历、对应页面或资产详情。应用建议后，卡片上的「打开文档」或「查看资产」可以直接核对结果。询问续费和支出时，助手会读取续费日历、应付合计与每月支出并标出来源。资产详情的「问 AI」和首页待处理的「让 AI 逐项分析」会带好问题打开助手，发送前可以修改。

建议有效期为 30 分钟，软件重启后需重新生成。确认时会核对资料版本，资料已变更、被删除或建议已应用时会拒绝再次写入，避免覆盖较新的内容。建议预览随问答保存在本机历史中；忽略建议不会删除已有对话。

仅需概括文档时，使用「允许本次读取正文并继续」即可，不必同时允许生成修改建议。正文片段会发送给当前配置的模型，密码等凭据仍通过本机账号面板查看。发送／停止按钮保持相同位置；内置能力面板展开、收起带有过渡，尊重系统减少动态效果设置。

## 查看 AI 订阅额度

新建 AI 资产时先选择来源：「订阅账号」进入网页授权；「API 调用用量」进入 OpenAI / Anthropic 用量配置；「仅手动记录」用于保存自己填写的资料，不代表已连接实时接口。

API 用量页点击「保存并验证连接」后验证一次，采集失败可重试并保留已保存的来源。查询范围取决于组织接口授权，同一组织无需按每个 Key 重复添加。Token 数量不等同于实际账单，软件不会根据网页订阅额度推算精确 Token 或费用。

1. 进入「AI 订阅 → 添加资产 → 订阅账号」，选择 OpenAI、Claude、Grok 或 Gemini，点击「网页登录授权」。密钥库锁定时先解锁。
2. 在服务商网页完成登录。等待授权时，应用直接显示「回调链接或授权码」输入框。OpenAI、Grok、Gemini 通常自动返回；没有返回时在输入框中填写本次登录生成的完整回调链接。Claude 填写完整回调链接或网页给出的 `code#state`，然后点击「完成授权」。不要只粘贴裸授权码，也不要使用上次登录的链接。
3. 界面依次显示等待回调、验证授权和同步额度。自动回调成功后无需再次粘贴；登录成功自动关联订阅并查询额度。重复授权同一账号不会重复新增订阅；用量查询失败仍保留已成功授权的账号，并显示「本机已保存授权」。
4. 打开订阅详情，点击刷新图标查询最新用量。查看额度来源、分类窗口、重置时间和查询时间；已用、总额度、剩余量仅在接口提供时显示。

OpenAI 显示 Codex 额度；Claude 显示 OAuth 返回的共享和模型额度；Grok 显示 CLI 周额度、产品额度及月度账单；Gemini 显示 Code Assist 模型额度。它们都不代表网页订阅的全部权益，可点击「查看官网权益」核对官网信息。账号套餐名也以授权或额度接口的实际返回为准。

订阅账号的额度会出现在「用量记录 → 订阅额度」。如果图表为空，到「用量记录 → 订阅与来源」查看该账号的卡片：每次查询失败的原因都会显示在卡片上，部分套餐（例如免费版）本身不提供额度查询。

「服务商未返回」表示字段缺失；权限、网络或登录错误会单独显示。刷新失败时已有数据保留为上次查询结果，不代表当前实时额度。令牌有效期不是订阅到期日，额度重置时间也不是续费时间。

额度查询返回 HTTP 403 表示服务商拒绝了本次请求，具体原因不能由状态码确定。它不表示尚未填写回调，也不表示额度为零。已完成、取消或过期的回调链接不能绑定到新登录；关闭授权界面后需要重新发起授权，使用新的回调结果。

手动填写入口继续保留，可以维护名称、月费、标签、说明和图片；编辑已授权订阅时会保留授权关联。模型问答继续使用「设置 → 模型与知识库」中的 API Key。具体条件见 [服务商授权教程](AI-ACCOUNTS.md)。

## 号码台账与订阅绑定

进入「号码管理」，记录已有号码、名称、服务商和到期日期；到期日期可按服务商账单手动维护。一个号码可关联多项 AI 订阅；解除绑定不删除订阅。点击号码卡片中的关联账号可打开订阅详情，详情中点击号码的「查看」会定位回该号码。同一号码保存为多条记录时，会按所选记录精确定位；点击「查看全部号码」恢复列表。

号码列表每页显示 50 条，按到期日排序；搜索与到期筛选针对全部号码进行，变化后回到第一页。搜索可以省略号码中的空格、括号和连字符。没有结果时可点击「重置筛选」。总览的号码待处理入口直接显示已到期和 30 天内到期的号码；系统通知定位到对应号码。

编辑号码时可搜索订阅名称、邮箱或服务商，搜索不会取消已勾选的账号。在订阅详情关联已有号码时，超过 20 个候选号码会出现搜索框，每次最多显示 50 个选项；继续输入可找到其他记录。

手机底栏可直接进入文档和号码。桌面终端和 AI 助手位于侧栏「更多工具」，展开状态会保存在本机；也能通过 `Ctrl+K` 搜索页面或操作。全局搜索先查全部资产，再最多显示 60 条结果，继续输入可缩小范围。

这里保存的是手动台账，不会向号码服务商查询实时状态，也不提供购买号码、接收短信、自动接码或自动续费。号码到期日期与 AI 订阅到期日期分别维护。号码和普通备注随资产资料保存在本机，未作为主密码凭据加密；不要把验证码、账户密码或恢复码填写进普通备注，分享导出文件前检查号码隐私。

## 备份与恢复

在「设置 → 数据」中创建加密备份或从备份恢复，无需先退出程序。资产 JSON 导出只含资产记录，不含密码、OAuth 令牌和聊天记录，仅用于迁移资产清单；完整迁移请使用加密备份。

### 创建加密备份

点击「创建加密备份…」，输入两次备份密码（10 至 256 位，可以与主密码相同），选择保存位置。软件先等待正在进行的保存完成，再把资产、文档、密钥库、个人资料、偏好设置、对话、知识库、用量记录、邮箱基线及云服务与探针配置打包成一个 `.zhiyu-backup` 文件，使用 scrypt 派生密钥并以 AES-256-GCM 加密。文件中除格式标识和加密参数外全部是密文，没有密码时连备份时间和资产数量也无法查看；任何字节被改动都会导致恢复被拒绝。备份不能保存到资料目录内，建议存放在另一块磁盘、U 盘或网盘同步目录。

以下内容不进入备份：界面缓存（Cache、GPUCache 等 Chromium 目录）、本机 AI 用量监控的日志索引（恢复后从本机日志重新扫描）、自动备份设置，以及外观、布局等只存在当前窗口中的显示偏好。

模型 API Key、云服务与探针连接、图床 Key 和 Linux.do 主身份由 Windows 系统加密，只能在当前电脑和当前 Windows 账户下解密。如需换电脑后继续使用，勾选「同时包含系统保护的凭据」：软件会先在本机解密，再用备份密码加密放入备份，恢复时交给新电脑的系统重新加密。勾选此项需要先解锁密钥库，未解锁时会先弹出解锁框。本机已无法解密的凭据会被跳过，完成提示中会列出数量。未勾选时这些凭据以原密文保存，在同一电脑恢复可直接使用，换电脑后需要重新填写。

备份中的密钥库仍由创建备份时的主密码加密。请同时记住备份密码和当时的主密码；两者都无法找回。

### 从备份恢复

1. 点击「选择备份文件…」，选择 `.zhiyu-backup` 文件。
2. 输入备份密码，点击「读取备份」。密码错误会提示「备份密码不正确」；文件损坏或被篡改会提示无法读取，不会改动当前资料。
3. 核对预览中的创建时间、知屿版本、资产数量、文档数量、密钥库凭据数量，以及是否包含系统保护的凭据。
4. 点击「恢复并重启」。软件准备好文件后自动重启，在任何功能读取资料之前完成替换。

替换前，当前资料会整体移到资料目录的 `restore-snapshots\时间戳` 文件夹，最多保留最近 5 份。恢复不满意时，退出程序后把该文件夹中的内容复制回资料目录即可回到恢复前状态。重启后，使用创建备份时的主密码解锁密钥库。若重启过程中断，下次启动会继续完成替换，已移入快照的原资料不会被覆盖。

### 自动备份

在「自动备份」中选择资料目录之外的文件夹，设置自动备份密码，选择每天、每 3 天或每周备份一次，以及保留最近几份，然后勾选「启用自动备份」。程序运行期间按周期在后台写入 `zhiyu-auto-日期-时间.zhiyu-backup`，只清理自己生成的旧文件，同一文件夹中的其他文件不受影响。可以随时点击「立即备份」。

自动备份密码由 Windows 系统加密保存在本机，不随备份迁移；从其他电脑恢复资料后，需要重新设置自动备份密码。自动备份不包含系统保护的凭据，换电脑前请手动创建一份勾选该项的备份。最近一次失败的原因会显示在设置中，失败后约一小时再次尝试。

## 常见问题

| 现象                           | 处理                                                                                                           |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 界面文字偏小或发虚             | 先在设置 → 外观调整界面大小；记录系统缩放与应用缩放，区分整窗和局部，必要时反馈显卡及多屏环境                  |

| 来源已保存但未连接             | 保存记录与验证结果分开显示，按错误核对权限和连接信息后重试；上次数据不代表本次成功                             |
| 主密码错误                     | 使用原密码；软件不提供找回或后门重置                                                                           |
| 模型返回 401                   | 检查 Key、Base URL 和服务商账号权限                                                                            |
| 模型不支持工具                 | 改用支持工具调用的模型或兼容网关                                                                               |
| 网站密码保存后找不到           | 打开对应密钥资产详情并解锁；没有账号记录时使用编辑录入，普通提示中不保存密码                                   |
| 邮箱提示先保存 IMAP 设置       | 在邮箱详情配置 TLS 主机和端口，并在账号区域保存用户名及授权码                                                  |
| 新增数量显示未知               | 首次检查或 UID 基线重置，不是零新增；完成下一次检查后再比较                                                    |

| 登录后没有自动返回             | 保持本次授权窗口开启，在「回调链接或授权码」输入框提交浏览器地址栏中的完整回调链接                             |
| 已保存账号，但回调输入框不见了 | 查看当前阶段；正在同步额度或授权已完成时不再需要输入。若本次授权已取消或过期，重新发起登录并使用新链接         |
| 固定授权回调端口被占用         | 应用会进入手动回调模式；粘贴本次回调链接，或取消后结束冲突的登录流程再重试                                     |
| 提示授权码或 state 不匹配      | 使用本次授权生成的完整链接或 `code#state`；过期或已取消时重新登录                                              |
| 授权页面拒绝客户端或地区       | 核对服务商限制，使用 API Key 接入模型                                                                          |
| 额度查询返回 401 / 403 / 429   | 401 核对登录是否失效；403 表示请求被拒绝，但不能仅凭状态码确定原因；429 稍后重试。403 不代表缺少回调或零额度   |

| 邮件图片未显示                 | 远程图片需逐封点击「加载本封图片」；超出内嵌图片限制或格式不支持时，可从附件入口下载后查看                     |

## 1.2.0：知屿工作区

知屿工作区沿用已有数据目录和凭据；浏览器配对按当前授权状态管理。

- **文档右键菜单**：在列表中右键目标文档，或使用右侧更多按钮；键盘可按 Shift+F10。选择删除后核对标题再确认。失败时草稿仍在，可处理错误后重试。
- **问答上下文**：桌面右侧搜索和切换对话、查看引用来源、回到引用消息。窄屏点击「对话上下文」展开。常用问题先填入输入框，可修改后发送。
- **文档正文许可**：默认只检索标题与关联信息。需要询问正文时，在发送前勾选「本次允许检索文档正文」；命中片段会发送给所选模型，回答保存在本机历史，下一次重新确认许可。
- **账号与文档**：在密钥库添加独立账号，凭据字段保存到主密码库；关联文档记录说明，正文不要用来代替加密密码字段。
- **用量明细**：在用量记录中按时间和来源筛选趋势与构成。本机监控启用后读取支持客户端的本地日志，无需解锁且锁库不暂停新采集；尚未生成日志、记录不含用量、缺少目录会分别提示，不会假造为零。

本机用量提示缓存无法读取时，不要直接清空历史。1.2.1 包含 Windows 文件虚拟化与 8.3 短目录名兼容修复，无需管理员权限；如仍显示失败，可保留缓存再检查文件权限或完整性。
