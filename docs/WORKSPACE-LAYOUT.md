# 工作区与侧栏布局

主内容容器始终使用主面板的全部可用宽度，桌面和 Web 不再分别限制为居中的 1180px、1440px。桌面宽屏仅保留 12–24px 的容器内边距，窄屏为 8px；文档和 AI 工作区使用自己的内边距。

## 侧栏规则

- 全局右侧概览固定在内容区域右边，宽度随空间在 264–320px 间变化。扣除主导航后的实际可用宽度达到 1280px 才显示；展开导航、缩小窗口或放大界面导致空间不足时隐藏，不留下空列。
- AI 上下文栏使用相同的宽度范围，按实际工作区宽度切换为单栏和上下文入口。
- 文档目录、设置分类和日历侧栏继续属于各自面板，边界不得超出主内容区。文档正文与对话消息保留各自的阅读行宽，不用正文行宽限制整个工作区。
- 资产卡片按最小 20rem 自动排列列数，不再固定最多三列；小屏下单列，不产生横向溢出。
- Web 顶栏与页面内容使用同一窗口宽度，不单独居中限宽。

## 实际回归

`scripts/workspace-layout-integration.mjs` 使用独立浏览器上下文、临时 Web 实例和合成资料，不读取个人工作区、不连接真实服务器。

```powershell
$env:NANPAD_QA_URL = "已启动的本地桌面样式预览地址"
node scripts/workspace-layout-integration.mjs
```

Web 部分读取真实 `dist-web` 构建，因此运行前需要 `npm run web:build`。桌面样式地址可使用正常开发服务或生产产物预览；本机不能占用 8080。设置 `WORKSPACE_LAYOUT_MODE=desktop` 或 `web` 可单独运行某一端。

验收覆盖 216 个场景：18 个导航页、Web 主机监控、详情与设置、主导航展开/收起、2048/1440/1024/390px，以及 125%/150% 缩放。检查工作区两侧边距、右栏宽度与贴边、内侧栏边界和横向溢出。旧产物在 2048px 下实测出现左右各 310px 的空列，回归先复现失败，修复产物通过。文档滚动和 Web AI 底部操作区的既有回归另行运行。

截图、测量结果和合成预览资料写入忽略的 `screenshots/`。`WORKSPACE_LAYOUT_PREPARE_ONLY=1` 仅准备合成资料后退出，可用于独立本机预览。
