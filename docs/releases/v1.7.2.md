# 知屿 Zhiyu 1.7.2（待发布）

当前只提交源码，未推送、未创建发布标签、未上传发行附件。以下为下一版本说明草稿。

用量工作区增加订阅来源管理、机场节点摘要与 v2rayN 本机流量查看，帮助区分服务商额度、客户端已保存统计和当前核心实时值。

## 用量概览与来源管理

- 「用量记录」分为「用量概览」与「订阅与来源」，统计图表和来源管理各有入口。新增与编辑在弹窗中进行，保存后验证一次，验证失败仍保留来源供编辑和重试。
- 编辑不回显连接凭据，留空保留原地址、用户名、密码或 API Key；来源类型保持不变。移除需确认，停止采集并移除连接凭据，已记录的历史用量保留。
- 类型、来源与模型筛选联动，同名来源增加区分标记，已移除来源的历史仍可筛选。模型仅作用于 Token，不影响流量和订阅额度。
- 相同规范化订阅地址重复或并发添加时复用已有来源；不同地址即使同名也不合并。更换地址清除旧节点缓存并重建计数基线，避免把新旧累计值的差额算作新增流量，旧历史继续保留。

## 机场额度与节点详情

- 机场卡片展示服务商返回的累计已用、剩余、总额度、到期和采样时间。缺失字段显示未提供，总额为 0 时显示不限额；刷新失败保留上次有效数据并标明状态。
- 节点列表和流量头分别解析，支持 URI、Base64、Clash 与 sing-box 节点摘要。能读到节点并不意味着服务商返回了用量头，也不能据机场总量推算各节点的计费流量。
- 展开详情读取缓存，可按名称、协议和主机搜索；展开与搜索不重新下载订阅，手动刷新后更新缓存。
- 订阅正文上限 2 MiB，最多展示前 1000 个可识别节点。订阅地址加密保存，普通缓存仅包含展示所需的名称、协议、主机、端口等信息，不保存节点认证参数或订阅原文。

## v2rayN 本机流量

机场节点详情中增加「v2rayN 本机流量」。Windows 自动查找客户端目录，也可手动选择；只读访问无需管理员权限或解锁密钥库，不修改 v2rayN 配置和数据库。

- **客户端已保存统计**展示逐节点累计与今日上传／下载，采用 v2rayN 保存的 KB 口径、按 1024 进位显示。这些数据通常在客户端退出时保存，不是实时值，旧日期记录不作为今日用量。
- **当前核心实时统计**读取 Xray 已启用的本机回环指标接口，按字节显示当前核心累计与本次监测增量。面板进入可视区域且页面可见时约每 5 秒读取，监测开始、节点切换或核心重置后重新建立基线。
- **归属必须明确**：机场节点按地址、端口、协议匹配，重复目标需名称唯一对应；不能确认时不将实时值归入该机场，可切换查看全部客户端节点和当前核心出口。
- 未发现可读实时接口或使用不支持的核心时显示明确提示，仍可查看客户端已保存统计。知屿不主动开启客户端统计或暴露新的接口。

已保存统计与实时字节采用不同口径，不能相加；本机统计也不与机场总量相加。它们不是机场逐节点账单，不代表所有设备的完整用量。
