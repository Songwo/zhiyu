# 司南 Nanpad 0.9.0

本版围绕缓存与性能：重复操作不再重复计算与下载，存储占用一目了然。

- 问答检索索引签名复用：资产与知识库未变化时跳过全量重建与写盘。本机基准 361ms → 10ms（约 36 倍，97 个片段），资产越多收益越大。
- 邮件会话缓存：文件夹列表（60 秒）与分页结果（30 秒）短时复用；正文与附件共享同一份已解析缓存，重复查看同一封邮件不再重复连接、下载与解析。锁库或标记已读自动清除。
- 邮件远程图片授权延续：按 Message-ID 记住已允许外部图片的邮件（最多 500 封），重开不再询问；可在「设置 → 存储」一键清除。
- 问答长对话窗口化渲染：默认挂载最近 40 条消息，更早的按需展开，长对话不再全量重渲。
- 主机指标采样内存化：不再每次采样重读整份历史文件并全量重算修剪；每条样本仍即时落盘，重启安全不变。
- 新增「设置 → 存储」：数据文件体积、邮件会话缓存与网页缓存占用一目了然，支持分类清理。缓存永不触碰资产、密钥库与凭据文件。
- 编辑资产时账号字段读取期间显示「读取中」并禁用输入；异步预填不再覆盖手动输入。

完整设计（含顺延项与理由）见 [v0.9.0 缓存与性能设计](https://github.com/Songwo/zhiyu/blob/main/docs/archive/plans/v0.9.0-caching-performance.md)。本版安装包命名为 `Nanpad-0.9.0-setup.exe`，扩展包命名为 `Nanpad-0.9.0-browser-extension.zip`（插件本版无功能变化，仅版本对齐）；可用下载以 [GitHub Releases](https://github.com/Songwo/zhiyu/releases) 为准。

## 缓存边界

密码、令牌与密钥值永不进入任何缓存层。邮件正文、附件与列表缓存只存在内存，锁库即清、不落盘；检索索引缓存内容与模型上下文同界（资产白名单元信息与导入文档片段）；图片授权记忆只保存 Message-ID 列表。磁盘加密缓存（正文跨会话复用）按设计文档的评审门槛顺延，本版未引入。
