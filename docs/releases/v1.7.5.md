# 知屿 Zhiyu 1.7.5

修复版本，已有资料沿用原数据目录，可在应用内更新。

## 修复

- 「设置 → 存储」中的「清空邮件会话缓存」和「清理网页缓存」在 1.7.4 及更早版本中总是提示「未知的清理范围」，无法清理。原因是主进程处理清理请求时读错了参数位置；本版修正后两个按钮均可正常清理。

## 升级与发行

Windows 附件为安装包 `Zhiyu-1.7.5-setup.exe`、便携版 `Zhiyu-1.7.5-portable-x64.zip`、浏览器插件 `Zhiyu-1.7.5-browser-extension.zip` 与 `SHA256SUMS.txt`；应用内更新沿用同次构建的 `latest.yml` 和 `.exe.blockmap`。安装包与便携版均未做代码签名，请核对 SHA256。浏览器插件仅同步版本号。

本机验证：新增的存储清理回归测试在桌面程序中通过两个按钮和桥接接口确认清理成功，未知范围仍被拒绝；该测试已加入 Windows 正式版流水线。完整打包程序集成测试由流水线执行。
