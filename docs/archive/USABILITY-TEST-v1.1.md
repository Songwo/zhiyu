# 司南 1.1.0 真人任务测试表

状态：待执行。计划邀请 3～5 位目标用户，目前尚无真人试用结果，也未代用户向第三方发出邀请。本文是可直接使用的任务表，不代表测试已经通过。

## 参与者与准备

覆盖独立开发者、自建服务使用者、主要管理 AI 订阅的个人用户；至少一位不熟悉 SSH。参与者使用自己的 Windows 电脑，记录分辨率、系统缩放、是否多屏和应用界面大小。可以在 125%、150%、175%、200% 系统缩放环境中选取实际可用样本，不将模拟像素比例写成真实显示器测试。

使用测试工作区、公开示例文档、无私人内容的图片和固定样本号码。涉及真实服务器、图床或组织 Key 时，由参与者自行输入，并先确认其允许本次连接；主持人不记录密码、Key、验证码、私人地址或完整导出文件。无需真实服务也可完成只记录、迁移、绑定和失败说明的理解测试。

每项任务先只读“给参与者的任务”，不提示按钮位置；卡住时先询问其预期，再提供一次提示并记录。记录成功／部分完成／未完成、用时、提示次数、首次误点、原话和是否信任当前状态。用时用于定位卡点，不把快慢当作用户能力评价。

## 任务

| 编号 | 给参与者的任务                                                           | 主持人观察与完成标准                                                                        |
| ---- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| T01  | 第一次打开司南，建立一个个人工作区并开始使用。                           | 能理解无需注册；默认名称可用；完成主密码确认；不被头像设置阻塞。                            |
| T02  | 把文字调到适合阅读的大小，然后恢复默认，再选一个喜欢的大小重新打开应用。 | 找到外观设置；能恢复 100%；重启后选择保留；主操作没有离开可视区；记录是否仍感觉模糊及区域。 |
| T03  | 先记下一台服务器的名称和地址，暂时不连接。随后编辑名称。                 | 能选择仅记录并保存；理解未采集；高级字段未被意外清空。                                      |
| T04  | 给已有服务器补充 SSH 配置，但不改变其已有标签和说明。                    | 能区分记录和连接；仅在获得授权时测试连接；编辑后非目标字段与已有凭据保留。                  |
| T05  | 创建一篇带图片和链接的部署笔记，关联到服务器，再解除关联。               | 文档自动保存；能说明图片保存位置；解除关联后文档仍在；重新打开能找到内容。                  |
| T06  | 把样本旧 Markdown 运维记录迁移到文档，改标题，再点击一次迁移。           | 找到统一入口；理解原文代码块；代码与链接文字保留；重复操作不覆盖新标题；知道原文仍可导出。  |
| T07  | 上传三张样本图片，在模拟第二张失败后完成剩余上传。                       | 识别哪部分成功；能重试剩余；成功图片不重复；能区分上传失败和文档保存失败。                  |
| T08  | 导入一个样本节点，并开始配置它的流量来源。                               | 节点／服务器上下文正确；知道面板根地址含自定义路径；可选筛选不会阻塞基本配置。              |
| T09  | 看到“来源已保存，连接尚未成功”后，说明你认为发生了什么并继续处理。       | 不把保存成功理解为采集成功；能找到错误与重试；知道保留的是上次数据。                        |
| T10  | 分别记录一个 AI 订阅和一个 API 用量来源，说明两处数字的含义。            | 选对入口；理解订阅额度与 API Token 的区别、组织查询权限，以及手动记录不会实时更新。         |
| T11  | 添加一个样本号码与到期日，关联到 AI 订阅，从订阅详情找回号码。           | 能完成绑定与返回；理解号码到期与订阅到期分别维护；不会期待软件接收短信或自动续费。          |
| T12  | 找到如何备份这些资料，并说明普通资产导出是否包含密码。                   | 能找到教程；知道凭据库独立；分享号码／文档导出前会检查普通字段。                            |

T07 可由主持人使用受控测试图床或测试桥接制造失败；不得故意破坏参与者真实服务。T09 无查询权限时验证失败说明的可理解性即可，不能标记为真实连接成功。

## 结束后的判断

优先修复数据丢失、旧凭据被清空、原文被覆盖和“错误被显示成成功”等问题。其次按重复出现的任务卡点排序，再处理视觉偏好。汇总实际参与人数和每项任务的完成情况，明确哪些只使用固定样本、哪些连接了真实服务；未进行的任务保留“未测试”。

每个问题提供可复现步骤、当时状态、预期和实际结果；不能稳定复现时标记“待复现”。修复后重跑对应自动化回归，再让出现该问题的参与者复试。自动测试通过不补填真人表格。
