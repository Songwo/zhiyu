# 司南 Nanpad 0.2.0

本版加入本机个人资料和首次主密码设置，修复问答及 Markdown 文档的排版，并加入四家 AI 服务账号的网页登录授权适配。

- 新用户设置姓名和主密码，已有用户保留原密钥库及资产。
- 模型回答、流式输出与引用支持标题、列表、表格、代码块；限制不安全链接和远程图片。
- OpenAI、Claude、Grok、Gemini 分别支持授权及用量查询，令牌加密保存在本机。
- 支持 OpenAI、Grok、Gemini、DeepSeek、通义千问、火山方舟和自定义模型地址配置。
- 本地 RAG、真实模型调用、只读 Agent 工具、来源引用、资产关系图与指标历史一并发布。
- 移除生产设置中的演示数据入口；补充使用、产品、安全和 AI 授权教程。

## 安装

下载 `Nanpad-0.2.0-setup.exe`，运行安装向导。Windows x64，当前安装包未签名，校验值见 `SHA256SUMS.txt`。升级前建议备份数据目录，已有主密码继续使用。

## 授权范围

OAuth 用于账号信息和额度查询；模型问答继续使用独立的 OpenAI 兼容 API Key。Claude 需要粘贴网页授权码，另外三家通过本机回调返回。Gemini 需要已开通 Code Assist 的账号。接口未提供的订阅到期日显示「未提供」，不会混用令牌有效期。

四家协议均有自动化回归测试；真实登录仍需账号持有人完成，受地区、权限和上游接口变化影响。未将协议测试表述为所有真实账号均已验证。当前只提供 Windows 安装包。

类型检查、298 项测试、桌面与网页构建、桌面集成和打包程序验收通过。网页 smoke 因 Grok 平台外部脚本的跨源加载错误未通过；桌面页面无该错误。远端私密 API Key 与四家真实账号登录未由自动化代用户验收。完整记录见 https://github.com/Songwo/zhiyu/blob/v0.2.0/docs/VERIFICATION-0.2.0.md 。
