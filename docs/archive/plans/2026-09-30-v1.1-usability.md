# 司南 1.1.0 易用性改进实施计划

目标：让个人用户在清晰的界面上完成录入资产、写带图文档、查看节点及 AI 用量。用户已批准上一轮建议全部实施并发布下一版本。基于现有 1.0.1 视觉和数据格式增量改进。

## 设计与兼容约束

- 显示：本机系统字体、可读的小字和状态对比度；稳定态弹窗解除模糊滤镜与多余合成；界面大小支持 100/110/125/150%，持久化且能恢复默认。系统 DPI 与应用缩放分开处理，不强制 device scale 为 1。窗口初始尺寸受屏幕工作区约束。
- 首次设置：工作区名称给默认值，头像后置；明确本地存储与无需注册。保留主密码校验和加密步骤。
- 服务器录入：名称与地址为主；明确“仅记录 / 配置 SSH”，其余信息收进可选高级区。已有资产编辑与隐藏字段必须完整保留，不清空凭据。
- AI 录入：先选订阅账号或 API 用量，订阅进入授权，API 进入对应采集向导；仍可“仅手动记录”，手填数据不伪装实时采集。
- 文档：统一服务器文档入口，沿用独立文档、自动保存、可解绑；旧 Markdown 运维记录提供显式、可重复安全的迁移，原文保留，失败不得清理旧资料。图片主操作为插入，展示保存位置、进度与失败重试；图床配置和已有内嵌图片迁移放次级操作。
- 节点：保存/导入后可直接进入流量连接，保留服务器与节点上下文。3x-ui/机场表单按类型显示，筛选放高级区；来源保存后进行一次明确由用户点击触发的验证采集，区分已保存、已连接、连接失败，失败保留来源并允许重试。
- 只读/手动数据不得标为真实采集；API Key、面板密码不得进入 UI 持久化状态、日志或截图。

## 并行接口与所有权

- root：`src/lib/store.ts`、新 `src/lib/usage-setup.mjs`、`server-nodes-panel.tsx`、`ui/global-nodes-hub.tsx`、`usage-workspace.tsx`、版本、翻译、发布文档、CI、整体验收。
- display：`electron/main.mjs`、`electron/preload.cjs`、`src/lib/desktop.ts`、`src/lib/settings.ts`、`settings.tsx`、`app-shell.tsx`、`styles.css`、renderer HTML、root HTML 与显示专用 helper/测试。
- composer：`onboarding.tsx`、`composer.tsx`、必要的字段组件、独立录入行为 helper/测试。
- documents：`documents-workspace.tsx`、`server-docs-panel.tsx`、`asset-documents.tsx`、`expand-layer.tsx`、`src/lib/documents.ts`、文档迁移 helper/测试（必要时文档存储模块）；不修改全局 CSS 或 store。
- 新翻译由各模块提供词条清单，root 统一写 `i18n-en.ts`。
- 使用 transient `useAppStore.openUsageSetup(draft)` 进行跨页面引导。draft 只有 `type?: '3x-ui'|'subscription'|'openai-api'|'anthropic-api'`、`serverId?: string`、`nodeId?: string`（纯节点 ID）、`name?: string`。该操作转向 usage 并关闭 composer/详情/菜单；消费后清除；不持久化，不包含凭据。
