# 知屿 1.3.0 浏览器协作

本次交付：Chrome / Edge CSV 双向迁移、同站多账号、登录页自动建议与用户选择填写、账号保存确认、网页文档保存提示，桌面与插件同版发布并同步下载页。

## 共享约定

- 所有账号使用现有 `account:<assetId>` 加密记录。新建导入或浏览器账号在加密记录内保留 `_browserAsset`（完整 Secret 元数据），让中途退出后可恢复资产索引；普通资产字段不含网址、用户名和密码。沿用账号删除先删加密记录的流程。
- `BrowserPasswords({vault, getAssets})` 服务提供 `preview(csv)`、`commit(ticket)`、`cancel(ticket)`、`exportCsv()`、`listForOrigin(url)`、`getForOrigin(id,url)`、`saveCapture(capture)`、`managedAssets()`、`clear()`。preview 只返回 ticket/总数/新增/重复/冲突/无效数/无密码预览 rows；commit 默认跳过冲突，不覆盖。saveCapture 对同站同账号同密码去重，不同密码新增版本（保留原账号）。同站不同账号独立保存。密码不回到导入界面。
- CSV 最多 10 MiB / 10000 条，支持 BOM、引号转义、换行与 Chrome/Edge 标准字段。导出准确保留凭据，明确明文说明，禁止通过改写公式前缀破坏密码；仅用于浏览器导入。
- Vault 新增原子 batch(entries) 和 readAll(prefix)；锁库取消待执行写入。服务锁库清除导入票据，所有写入与重复判断串行。
- 桌面 `passwords.previewImport()` 用系统选择器读取 CSV，`commitImport(ticket)` / `cancelImport(ticket)` / `exportCsv()` 用系统导出确认与文件选择器。`onChanged` 推送新增 Secret 元数据。main 合并 managedAssets 到 store load/save，保证旧渲染快照不会抹去后台新资产。
- 本地桥 POST `/v1/accounts/list` {url} -> {accounts:[{id,title,username}], selectionToken}；POST `/v1/accounts/fill` {url,id,selectionToken} -> {username,password}。一次性短期 token 绑定配对客户端和精确 origin，HTTP 非本机不填写。接口返回前重新验证锁库与会话。
- POST `/v1/accounts/save` {url,title,username,password} -> {id,status}。仅扩展用户确认后发送；默认保留同账号的不同密码，避免误覆盖。
- POST `/v1/documents` {url,title,text} -> {id,status}。正文上限 200000 字符，主进程生成纯文本 Tiptap 内容并添加来源链接，按规范化来源去重，已有来源返回 existing，不静默覆盖。
- 插件后台所有内容脚本请求验证 sender.id、顶层 frameId、sender.url 与当前 tab URL 相同；实际 origin 从 sender 得到，不相信传入 URL。每次填充前后验证 tab/document 未导航。账号候选、密码不进入持久化 storage。用户 trusted click 才请求密码/保存；不自动提交登录。
- 提交采集原接口继续兼容。自动提示可关闭；文档只在用户确认时读取可见正文，不抓取未加载、跨域或 canvas 文档，空正文保存来源链接并提示。
