# Web 与桌面能力对照

Web 与桌面复用同一份资产、卡片、文档、检索和分析界面。部署 Web 镜像并不等于自动升级所有已有自托管实例；实例需要更新镜像并重建容器，挂载的数据目录保持不变。

## 已共用或本次补齐的能力

| 能力                                           | Web 实现                                               | 验证方式                                                              |
| ---------------------------------------------- | ------------------------------------------------------ | --------------------------------------------------------------------- |
| 资产、标签、自定义类型、费用、续费与关系       | 共用渲染与业务逻辑，服务器保存工作区                   | 原有全量单元测试与 selfhost 浏览器回归                                |
| 支付卡与 eSIM、银行/BIN、图标、3D 翻转、期限   | 共用卡片组件与目录                                     | 共用逻辑测试；Web 构建与浏览器回归                                    |
| 卡片/账号私人资料、解锁和复制                  | 浏览器本地解密密钥库，服务器只保存密文                 | Web 密钥库与桌面双向兼容测试                                          |
| 富文本/Markdown、自动保存、图片设置            | 共用编辑器，明确显示「保存到服务器」，图床走 Web 桥    | 原有编辑器回归、Web 文档事件测试                                      |
| 文档账号提取、选择与修改、去重、关联           | 浏览器本地复用解析器；批量加密一次写入密钥库           | 解析/导入单元测试、批量写入与锁库测试、Web 浏览器回归                 |
| Linux.do 主身份、昵称/头像、公开帖子           | 安全轮询授权，原会话预览并确认；凭据在 server 目录加密 | 真实本机 HTTP OAuth 链路、取消/过期/重放/会话隔离测试、Web 浏览器回归 |
| Exa 查询、结果与实时步骤                       | 同源 RPC 连接原身份服务，不把共享 Key 交给浏览器       | 真实本机 HTTP 检索与记账；Web 浏览器操作                              |
| 免费/已购次数、消耗与购买记录                  | Web/桌面同一 Linux.do 主体共用远端账本                 | 免费 50 次耗尽、失败不扣次、幂等、未配置禁止购买测试                  |
| Jev 设置、规则、原文高亮/下划线/定位、字号行距 | 服务器加密用户 Key；短请求轮询逐段进度                 | 真实本机 HTTP TypeSafe 合成供应商；Web 浏览器检查原文和文档数量不变   |
| TOTP                                           | 同一算法，浏览器内计算                                 | 既有算法和 Web 密钥库测试                                             |
| SSH、SFTP、采集、域名证书、Cloudflare、AI API  | 原有 Web 服务端桥                                      | 既有桥与服务测试、Web 构建与 selfhost 浏览器回归                      |
| 备份、恢复与同步                               | 同一工作区格式及 ZSP 协议；浏览器加解密密钥库          | 既有恢复、双向密钥库兼容与同步测试                                    |

本机 HTTP 合成供应商验证实际序列化、鉴权、任务、错误和 UI，但不等于使用真实账号/付费 API 验收。没有真实 TypeSafe Key 时不会宣称真实 Jev 请求通过。LDC 商户与可信 Exa 余额未配置时继续禁止积分购买，不能为展示功能而开启扣分。

## 有明确运行环境差异的能力

| 桌面能力                                              | Web 对应方式或限制                                                                         |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Windows 原生嵌入终端                                  | 浏览器使用 xterm 与服务器 SSH；不在网页内嵌 WPF 控件                                       |
| 本机 SSH agent / 私钥路径                             | 浏览器加密密钥库中的私钥正文或密码，连接时交给服务器暂用                                   |
| 本机日志、v2rayN 程序目录                             | Web 的「本机」是服务器，不是访问网页的电脑；不读取访客机器上的程序目录                     |
| 系统托盘、开机启动、关闭到托盘、原生通知              | Web 使用浏览器页面与服务器提醒推送，不能控制访客的系统托盘/自启                            |
| 桌面自动更新、打开资料目录                            | Web 检查新版本并提示升级镜像，不在浏览器操作服务器文件管理器                               |
| 浏览器扩展配对与密码 CSV 迁移                         | 当前扩展仅连接桌面回环服务，Web 尚无扩展配对和 CSV 迁移流程                                |
| AI 账号/邮箱 OAuth、旧独立身份资产的自建 Connect 授权 | 仍依赖桌面授权窗口；Web 可配置模型 API、用量 API、邮箱授权码；Linux.do 主身份已有 Web 授权 |
| 浏览器关闭后检查新邮件                                | Web 服务器不保存邮箱登录凭据，当前不能持续代收；定时续费提醒仍可服务端推送                 |

这些差异不会用伪按钮或模拟成功掩盖。卡片、文档、资产等工作区资料可以同步；操作系统/服务器保护的身份和 API Key 配置不随工作区同步，需要分别配置。

## 复验命令

```text
npm run typecheck
npm run lint
npm run i18n:check
npm test
npm run web:build
node scripts/web-selfhost-integration.mjs
node scripts/web-research-ui-integration.mjs
```

浏览器回归使用临时实例、合成账号、合成供应商和真实 Web 正式构建，检查桌面/390px、明暗主题、原文未改动、无多余文档、控制台无错误。截图保存在忽略的 `screenshots/`，不读取日常工作区或真实用户数据。
