# Web 与桌面能力对照

Web 与桌面复用同一份资产、卡片、文档、检索和分析界面。部署 Web 镜像并不等于自动升级所有已有自托管实例；实例需要更新镜像并重建容器，挂载的数据目录保持不变。

## 已共用或本次补齐的能力

1.17.8 共用容器自定义告警规则、事件确认与维护静音；共用邮箱—账号—资产—文档链路与号码订阅关系；共用 S3 加密自动备份配置、上传历史与部分失败报告。Web 文档关联从服务器读取，底部 AI 权限在窄屏和安全提醒展开时保持可操作。Web 备份密码、S3 凭据由服务器密钥保护，需分别同意服务器保管；桌面使用系统安全存储，均不把自动备份密码或 S3 凭据装入备份。

新增验证脚本：`web-container-alerts-integration.mjs`、`web-relations-integration.mjs`、`web-s3-backup-integration.mjs`、`web-agent-layout-integration.mjs`。使用真实构建、临时实例及合成数据；S3 验证通过独立 SigV4 校验的本机 HTTP 服务，不代表真实云账号在线验收。

## 1.17.6 补齐能力

- 密码 CSV 在浏览器本地解析和导出，预览不显示密码，导出明确确认明文风险。
- 扩展连接打开且解锁的 Web 标签页，支持候选填写、确认保存及文档采集。要求 HTTPS/回环；锁库、刷新、关闭后重新配对。
- AI 与邮箱 OAuth 提供官方授权链接和完整回调粘贴，浏览器不监听访问者电脑端口。
- 旧独立身份资产支持重新授权、确认预览、刷新资料与公开帖子关联文档。与主身份分别配置。
- 默认关闭的后台邮件检查，明确同意后服务器加密保管所选邮箱凭据；首次建基线，推送只含数量和时间。关闭并保存即清理邮箱凭据。
- SSH 错误可直接打开凭据面板，使用已保存凭据测试；输入完整主机与端口确认重置指纹，清除后不自动重连。

## 有明确运行环境差异的能力

| 桌面能力                                 | Web 对应方式或限制                                                     |
| ---------------------------------------- | ---------------------------------------------------------------------- |
| Windows 原生嵌入终端                     | 浏览器使用 xterm 与服务器 SSH；不在网页内嵌 WPF 控件                   |
| 本机 SSH agent / 私钥路径                | 浏览器加密密钥库中的私钥正文或密码，连接时交给服务器暂用               |
| 本机日志、v2rayN 程序目录                | Web 的「本机」是服务器，不是访问网页的电脑；不读取访客机器上的程序目录 |
| 系统托盘、开机启动、关闭到托盘、原生通知 | Web 使用浏览器页面与服务器提醒推送，不能控制访客的系统托盘/自启        |
| 桌面自动更新、打开资料目录               | Web 检查新版本并提示升级镜像，不在浏览器操作服务器文件管理器           |

这些差异不会用伪按钮或模拟成功掩盖。卡片、文档、资产等工作区资料可以同步；操作系统/服务器保护的身份和 API Key 配置不随工作区同步，需要分别配置。

## Web 安全边界

公开 Web 会增加攻击面，敏感资产建议优先使用桌面端。仅使用可信部署、HTTPS、两步验证及可信设备/扩展。恶意脚本、扩展或服务器提供的恶意页面仍能在解锁后读取明文。

SSH/邮箱执行所需凭据交给服务器暂用；AI 和独立身份令牌在明确同意后由服务器加密保管，管理员仍能访问，不属于浏览器端到端加密密钥库。邮箱身份 OAuth 只核验地址，刷新令牌返回浏览器加密保存，服务器不持久保存此次令牌。桌面端同样依赖本机安全。
