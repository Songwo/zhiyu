# 支付卡与 eSIM

在侧栏「账号与订阅」中打开「U 卡与支付卡」或「eSIM 卡」；「新建资产」也有对应入口。

## 支付卡

- 卡组织预设包含 Visa、Mastercard、UnionPay、American Express、Discover、JCB、Diners Club、Maestro、RuPay、Mir、Elo、Troy，可以直接填写自己的卡组织。
- 发卡服务商与卡组织分开记录。提供常见服务商名称作为录入预设，也支持手动填写；预设不代表服务在所有地区均可申请，不自动填写余额、费用或有效期。
- 粘贴卡片说明，可以提取其中明确标注的服务商、卡组织、信用/借记/预付，以及虚拟/实体属性。信息可修改；仅有服务商名称时不猜测信用属性。
- 卡号前缀可以辅助识别部分常见卡组织，只保存尾四位。用于辅助识别的输入不会写入资产快照；需要保留完整卡号时，可另行在卡片背面保存到加密密钥库。本机识别不请求外部 BIN 服务，也不验证卡片可用性。没有覆盖的号段可以手动指定卡组织。
- 按卡面填写有效月份，以该月最后一天作为日期级截止日，支持闰年。卡面使用月/年显示，详情显示完整日期；不猜测发卡商的具体失效时刻。

### 国内银行与地域

内置 30 家国内银行预设：工行、建行、农行、中行、交行、邮储、招行、中信、光大、华夏、民生、平安、兴业、浦发、广发、浙商、渤海、恒丰、北京银行、上海银行、江苏银行、南京银行、宁波银行、杭州银行、成都银行、长沙银行、重庆银行、广州银行、徽商银行、大连银行。全称、常用中文简称和英文代码均可用于识别说明；预设之外仍可手动填写服务商。

录入识别卡号时，本机参考 889 条离线号段。最长前缀优先，完整卡号同时检查长度，同号段有多个可能发卡行时不猜测。6 位或 8 位前缀只用作提示，完整输入才自动补充空白字段。已有服务商、卡组织和地区不被覆盖，确认后可点击「采用识别结果」。加密资料录入同样提供银行参考结果与显式采用操作。识别不验证真实账户、卡片可用性、信用属性或权益，不根据卡组织判断发行地区；没有覆盖或发生变更的号段需要手动确认。

列表增加独立地域筛选：中国大陆、港澳台、海外、全球 / 多地区、未设置地区，显示各分组数量。发行地区（eSIM 为覆盖地区）可从预设选择或自行填写；默认按地区文字分组，也可手动指定地域分组，适用于跨区域卡片和自定义地区。地域信息通过原有服务资产通路导出、备份和同步。

卡面用发卡行或服务商的文字标识、独立配色、细纹与金属芯片建立辨识度；自定义服务商使用稳定配色，重载不随机变色。地区、卡片形态、尾号和有效期各有固定位置。样式是应用内设计，不表示官方发行卡面、卡片等级或认证关系。详情正反面共享同一套配色。

### 离线参考数据来源

号段来自 `caijf/bankcard`，固定提交 `79af3e5d1bd381537c2f0e95c03584c911963d1e` 的 `src/data/bin.ts`，保留上述银行的 6 位及更长号段与卡号长度，丢弃卡片资金属性。属于历史参考数据，不保证覆盖新增的 8 位 BIN 或最新发行变化。MIT 许可证原文随数据保存在 `electron/services/data/bankcard-LICENSE.txt`，一同进入桌面包。运行 `node scripts/update-bank-bins.mjs` 可从固定版本重建；生成文件记录源文件 SHA256，更新版本前应审核数据与许可证。使用时无网络请求，不上传完整卡号。

## eSIM

记录服务商、套餐、覆盖地区、运营商、可选绑定号码、ICCID 尾号和套餐流量。流量是用户记录的套餐总量，不作为实时剩余量显示。

套餐到期与保号截止独立保存。提供服务商明确给出的套餐到期日时优先使用该日期；只有实际激活日期与有效天数齐全时，才按激活当天为第一天估算最后有效日。未激活时不自动生成期限。不同运营商的激活与计时规则不同，精确时刻以服务商为准。

最近期限进入现有续费日历和提醒。卡片详情和列表同时展示套餐与保号日期，可通过「更新期限」修改实际日期。卡片有效期不会因为填写了月费或年费，就被虚构为按月自动延长。

## 3D 翻转与快捷复制

卡片详情居中展示，点击正面或「翻到背面」可以查看背面操作，「翻回正面」可随时返回。桌面有轻微透视与随指针移动的高光，减少动态效果设置下保留翻面功能并关闭动画。

背面「录入或编辑加密资料」支持：

- 支付卡：完整卡号、持卡人、安全码及加密备注。
- eSIM：完整 ICCID、EID、激活码及加密备注。

完整资料独立保存在密钥库的 `card-private:<资产标识>` 记录中。普通资产、导出 JSON、关联和 AI 元信息只保留原有公开字段，不包含这些完整资料。保存完整卡号或 ICCID 后自动更新公开尾四位，卡号前缀与已选卡组织不一致时给出核对提示，不自行覆盖手动选择的卡组织。

背面默认隐藏敏感值。点击眼睛按需显示，20 秒后、窗口失焦或页面隐藏时重新遮挡；锁库、翻回正面或离开详情时立即隐藏。复制按钮每次重新检查解锁状态，锁定时完成解锁后继续原来的复制，取消解锁则不复制。复制已保存的资料无需先显示全文；尾号可独立快速复制。

删除卡片时，输入完整名称确认后，还需解锁并移除对应密钥库记录，再删除资产与关联；文档保留。已有备份不随之删除。

## 关联、凭据与保存

卡片复用服务资产的数据通路，能关联账号、邮箱、AI 订阅、其他资产与文档，并参与已有费用统计、导入导出、加密备份及桌面与网页同步。进入卡片详情，可以添加资产关联、创建或关联文档、管理加密凭据，并从原有「问 AI」入口提问。

卡片名称、服务商、尾号、期限与普通备注属于资产元信息。完整卡号、CVV、ICCID、EID 与激活码在卡片背面录入加密资料，其他敏感内容可放在加密备注中；不要写在普通备注。卡面样式由代码绘制，银行和卡组织标识读取随程序内置的本地图标，不向外部品牌图片服务发送跟踪请求。

## 内置品牌图标

内置 102 个银行、AI、云平台、系统、邮箱、软件及卡组织标识。常见 AI 包括 OpenAI、Claude、Grok、Gemini、DeepSeek、通义千问、豆包、MiniMax、Kimi、智谱、Perplexity、Cursor、Copilot、Mistral、Ollama、OpenRouter、Hugging Face；云平台包括 Cloudflare、AWS、Azure、腾讯云、阿里云、华为云等。

支付卡按发卡银行显示银行图标，卡组织独立显示。已有资产卡片、资产详情、AI 授权列表与编辑器预览按服务商、注册商、签发者、可信域名或系统名称匹配。用户上传的资产图片始终优先，删除上传图片后恢复内置图标；无法匹配或图片损坏时保留原有通用图标。不访问任意 favicon，不下载未收录的图标，不把图标文件写进资产快照。

图标在 `public/brands/`，来源、许可证与 SHA256 记录在该目录的清单及说明中。SVG/PNG 按需加载，不引入完整图标包的运行依赖。银行标志只用于识别，不表示官方合作或卡片认证。

## 删除确认与性能

普通资产详情的删除入口需要逐字输入完整资产名称，名称不匹配时按钮禁用，取消保留原记录。已有加密账号保留原来的解锁删除流程。

编辑器、设置与详情在首次需要时加载；终端保留原有挂载方式，维持跨页面会话与原生控件的初始化顺序。浮层首次加载后继续保留挂载，保留关闭动画与事件订阅。桌面包只保留英文、简体中文、繁体中文运行时语言资源，保留 Chromium 运行文件、许可证与现有运行依赖。

## 本地验证

```text
npm run typecheck
npm run lint
npm run i18n:check
npm test
npm run desktop:build
node scripts/cards-desktop-integration.mjs
npm run web:build
node scripts/web-selfhost-integration.mjs
```

`cards-desktop-integration.mjs` 使用临时资料、合成卡号与演示资产，检查识别、保存、关联重载、eSIM 期限、手机布局、删除确认与控制台。新纯计算回归在 `electron/services/managed-cards.test.mjs`，覆盖闰年月末、日期级倒计时、非法数据、敏感字段剔除与续费日期边界。测试不会访问真实发卡商、查询真实余额、连接用户服务器或修改日常资料。

`scripts/card-identity.test.mjs` 覆盖全部国内银行的数据可用性、最长号段、重复号段歧义、长度限制、手动字段保护、地区分组与稳定卡面样式。复制集成拦截浏览器剪贴板接口，以验证真实解密输出及取消解锁行为，不覆盖系统剪贴板。
