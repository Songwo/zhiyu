# 知屿 Zhiyu 产品介绍

知屿面向维护多种数字资产的个人开发者、独立产品负责人和小型运维场景。主机、域名、证书和 AI 订阅不再分散在多个记录表中，可以按项目标签聚合，再通过关系图查看依赖。本文对应 1.7.2，升级沿用原数据目录和凭据库。

也适合管理「我在哪个网站注册过账号，用的是哪个邮箱」这种日常问题。网站名称和标签负责帮助查找，登录网址、用户名和密码保存在本机加密库，注册邮箱通过资产关联记录。

## 浏览器与本机资料连起来

把 Chrome / Edge 导出的密码 CSV 导入知屿，先核对重复与冲突，再统一加密保存。相同网站的个人、工作或家庭账号独立存在；导入不会自动覆盖不同密码的旧记录。需要迁回浏览器时，可以导出兼容 CSV，导入后删除明文文件。

配套插件在登录页提示本站已有账号，选中后填写，由你提交登录。首次登录的新账号也能一次确认保存；同账号出现不同密码时保留原记录并新增版本。插件不直接读取浏览器原生密码库，不承担无确认的自动登录。

腾讯文档、微信公众号文章、飞书、语雀等页面可提示保存当前可读文字与来源链接。保存后的快照进入文档工作区，按需关联账号、服务器或项目资料；它不下载未加载的原生文档，也不持续同步线上修改。文档记录用途与说明，密码仍留在独立加密字段里。

## 主身份与本人帖子

首次设置或「设置 → 个人资料」可使用 Linux.do 登录并绑定主身份，普通用户无需申请 Connect 应用或填写密钥。系统浏览器完成官方授权后，先核对用户名、平台返回邮箱和信任等级，再确认绑定。缺失字段显示未提供；也可以不绑定，继续在本机使用。

昵称和头像分别选择是否同步，默认保留本机值。开启同步只改变显示来源，原有自定义资料仍保留；实际手动修改某个字段会关闭对应同步。更换为不同社区账号需要明确确认。登录凭据独立使用操作系统安全存储加密，锁库仍可管理主身份，Linux.do 登录不代替本地主密码。

个人资料中的「我的帖子」可按需加载本人公开主题和回复，勾选后读取全文、保留来源，保存为新文档；不读取私信或受限帖子。论坛拒绝访问时显示实际错误，不用摘要替代正文。主身份不是密钥库账号资产，保存时不会创建虚构的账号关联；需要时可在文档中关联已有资产。

退出登录清除本机登录凭据和帖子缓存，保留身份展示、同步偏好和已保存文档；刷新资料或读帖需要重新登录。旧版密钥库身份资产及文档关联继续保留。1.7.0 已完成本机真实授权与资料同步验证；字段仍取决于平台返回，不能据此推断任意头像或受限帖子均可读取。具体步骤见[主身份与个人资料](MAIN-IDENTITY.md)。

文档中明确标注的账号字段和 Markdown 表格可在本机提取，核对并勾选后加密保存为账号，再关联来源文档。这一步不请求模型，也不自动删除原文里的敏感内容。账号详情可管理网站 TOTP 动态验证码，查看剩余时间并复制。

文档支持 Markdown 源码编辑与预览，导入时保留原文，表格、任务列表和代码块按 GFM 展示。转为富文本前会说明格式变化并要求确认，适合同时保存技术笔记和普通图文资料。

## 日常场景

早上打开总览，检查离线资产和即将到期的项目。进入主机详情比较近期 CPU、内存与磁盘变化，需要操作时打开 SSH 终端。查看域名及证书关联，避免只续费域名却漏掉证书。为同一产品的主机、域名、邮箱和密钥打相同标签，在分组视图集中维护。

Cloudflare Workers、个人博客、自建邮箱等无需服务器登录的项目可保存为「服务资产」，并与文档、账号及其他资源关联。服务状态由用户维护，不自动发起探测。服务器监控另有「仅手动刷新」或 1、5、15、30、60 分钟周期，默认 5 分钟；窗口可见且密钥库解锁时才进行自动采集。

AI 订阅可以通过快速登录关联账号，按来源查看可读取的分类额度和重置时间。不同服务商公开给客户端的范围不同：Codex、Claude OAuth、Grok CLI、Gemini Code Assist 的额度不能统一视作网页订阅的完整权益。接口拒绝访问时显示错误，刷新失败时标明上次查询结果，方便判断数据是否仍可参考。

用量页通过图表和明细核对流量、API Token、本机日志与订阅额度。本机采集完成后更新已有统计，切页复用缓存；历史峰值很高时，今日明细和真实坐标上的小额用量标记仍能看清当前记录。该能力只覆盖实际可读取的客户端日志，不等于监控所有 AI 软件的请求。

## AI 的职责

把运维手册导入本地知识库后，可以询问「哪些资产需要优先处理」「这个域名关联哪些主机」「本月 AI 订阅费用是多少」。模型根据当前记录与检索片段回答，引用来源可展开核对。

模型根据已有资料回答，主机状态由实际探测产生，金额和日期以资产记录或服务商返回值为准。需要修改资料时，可以让 AI 提出文档改名、正文局部替换、账号名称与标签调整或关联建议；每项展示修改前后和依据，经用户确认与版本校验后保存。

标题改名只需标题信息，读取或修改正文时才申请本次正文许可。缺少权限时，回答下方可直接允许本次使用并继续原问题；许可不会延续到下一条问题，也不会让模型自行写入。密码、用户名、登录网址及敏感备注仍通过本机账号面板维护。

查找密码时，模型返回的是资产详情的位置，不接触加密库中的密码。查询「有哪些邮箱分组」「某个分组有哪些账号」时，模型通过本地目录读取空组、未分组及账号归属。这些是知屿的账号收纳组，与服务器上的收件箱、已发送等邮件文件夹不同。

需要检查收件箱时，由用户为本次提问开启实时查询；本机邮箱服务读取加密凭据完成 IMAP 认证，模型只收到数量和检查时间，不读取标题、正文或附件。查看本地分组无需实时查询许可，但分组名称和邮箱地址会作为元信息发送给配置的模型。

这不等于所有信息都不会联网：用户问题、近期历史、检索命中的公开资产字段和导入文档片段会发送给配置的模型服务。完整数据流及保护范围见 [安全与备份](SECURITY.md)。

## 本机工作方式

桌面端保留资料、资产、指标和对话，资产凭据由主密码单独加密。Linux.do 主身份通过独立登录服务完成授权，身份资料、登录凭据与帖子缓存使用系统加密保存为 `main-identity.enc`；该服务不接收本机资产、文档或主密码，不提供资产云同步或团队权限。网站账号与 AI 订阅令牌仍存入主密码库，两类登录凭据的保护方式不同。

个人头像和资产图片可从本地文件上传、更换或移除，绑定主身份后还可选择下载并显示平台头像。未启用图床时本地图片的处理与保存都在本机完成；文档和资产封面可选择上传到自行配置的图床，个人头像仍保存在本机。

## 邮箱阅读与收纳

邮件阅读器增加安全 HTML 与 Markdown / GFM 排版，标题、表格、引用和代码块不再统一挤成纯文本；仍可切换到解析后的原文。列表和阅读区分别显示加载骨架，选中与未读状态更清晰，窄窗口保留列表和正文的切换。

邮箱头像及所属分组可直接编辑，发件人支持本地自定义头像；没有图片时显示首字母，应用不自动向外部头像服务发送邮箱地址。正文远程图片默认拦截，用户可为当前邮件单独加载；图片服务器可能因此获知 IP 地址和阅读时间。随邮件携带且符合限制的 CID 图片在本机展示。

邮箱首页支持按分组名称搜索，真实 Agent 增加分组及账号目录查询，能够回答空组、未分组、账号归属等问题。密码、邮件正文、草稿和图片不进入这些工具结果。

已有文件夹收纳、批量移动、IMAP 搜索、未读筛选、附件下载、回复、转发和 SMTP 写信继续保留，草稿保存在主密码加密库。所有发信必须经过用户确认，正文不进入 Agent 或 RAG。连接条件及限制见 [邮箱工作台](MAIL-WORKSPACE.md)。

## 已有工作流

浏览器助手提供密码迁移、账号建议与选择填写、确认保存和网页文档快照。桌面与插件解锁配对后才开放加密账号读取，锁库或撤销连接后停止。只记录网站时仍有独立入口；具体安装和网页边界见 [浏览器助手说明](BROWSER-EXTENSION.md)。资产列表支持批量标签整理和统一关联，详情可搜索多选，关系图可手动连线。

网站账号可以从粘贴的网址预填，选择密码类型后录入完整登录信息，并关联注册邮箱。凭据保存失败时保留表单，避免生成没有凭据却提示成功的记录。

邮箱增加手动检查和本次问答授权查询，区分总数、未读与新增数量。邮件数量提醒可以接入 Telegram、Server酱 / 微信、企业微信群机器人和 WxPusher；默认关闭，桌面端运行且密钥库解锁时才工作，首次检查仅建立基线。推送内容不含邮箱地址或邮件内容。

已有 AI 分类额度、回调输入框、主题化下拉菜单、头像和资产图片继续保留。真实账号 HTTP 403 的上游限制没有因此消失，仍以服务商实际返回为准。本版不提供个人微信自动登录。详细操作和限制见 [使用教程](USER-GUIDE.md)。
