# 知屿 Windows 安装体验提案

设计已转为 `build/bootstrapper/` 中的 Windows 原生 WPF 在线安装器；网页预览仍用于评审，不修改系统。正式程序采用真实下载字节、大小与 SHA256 校验，调用 NSIS 安装引擎。发布状态以 GitHub Release 为准。

## 视觉与流程

沿用知屿现有蓝色 `#3b6fe0`、浅蓝 `#eef4fe`、青色 `#208d98` 与品牌图标。正文使用 Windows 的 Segoe UI / 微软雅黑，左侧用文档、账号、主机围绕知屿标志的动效表达“连接”。右侧依次呈现安装偏好、下载与安装、完成三步。动画跟随安装状态，暂停时停止，系统设置减少动态效果时关闭动画。

流程：选择目录与安装偏好 → 必要时由 Windows 请求授权 → 下载 → 校验 → 安装 → 完成并启动。预览可切换正常、无 D 盘、下载中断三个场景，并支持更改目录、暂停、继续、取消与重试。

## 默认行为

- 全新安装优先 `D:\Apps\Zhiyu`；正式实现必须检测固定磁盘是否存在、空间是否足够、目录 ACL 是否允许写入。没有 D 盘时回退到当前用户 `%LOCALAPPDATA%\Programs\Zhiyu`。预览中的用户名为示例，不可用于正式安装。
- 升级沿用已登记的安装位置，保留已有设置，不因默认 D 盘而迁移旧安装或用户资料。现有 `build/installer.nsh` 的目录兼容与快捷方式身份修复需要保留。
- 默认仅当前用户安装；桌面快捷方式默认创建；开机自启默认关闭。不能用“不开快捷方式”删除用户原有的自建快捷方式。
- 全用户安装需提升权限；当前用户安装先检查目标目录写入权限，不可写时提示换目录或改选所有用户安装，避免 UAC 中换用其他管理员账号后把资料入口装到错误的用户。不能承诺 D 盘一定无需管理员权限。使用 Windows 系统授权窗口，不绘制仿 UAC 弹窗。
- 不请求网络防火墙例外、浏览器密码、通讯录等与安装无关的权限。安装目录与用户数据目录分开，不把账号数据随程序卸载或升级清理。
- 安装后启动普通用户进程，不能继承安装器的管理员权限运行日常应用。

## 原生在线安装器实现

完整程序继续由 Electron Builder NSIS 打包。在线引导器通过 Windows 自带的 .NET Framework/WPF 展示界面，不内置另一份 Electron，不依赖 WebView2；实际体积以对应 Release 附件为准。完整程序仍需另行下载。

`npm run desktop:online` 在离线安装包完成后编译原生引导器，把该版本的官方 HTTPS 地址、文件长度与 SHA256 固定到程序资源中。执行前再次校验并持有文件读取锁；未知文件、错误长度和错误哈希都不得执行。载荷进程只接受经过验证的安装路径与固定参数。

现有离线安装包、便携版与应用内自动更新继续提供。在线包为独立的 `*-online-setup.exe`，`latest.yml` 继续指向离线包。当前没有受信任签名证书，明确按未签名产物发行；签名接入条件见 `docs/WINDOWS-SIGNING.md`。

自启偏好传给 NSIS 的专用参数，由安装引擎按安装范围写入 Windows Run 项；升级沿用已有偏好，卸载只删除指向当前程序的值。原生下载支持取消与失败后重新下载，不宣称支持断点续传；写入阶段显示不定进度且不可强制中断。网页中的暂停和演示进度仅属于预览。

## 预览与验证

独立启动：`node scripts/installer-preview-server.mjs`，提供 `/installer-preview/`；不需要启动主应用或连接数据库。已有开发服务器运行时，也可直接访问相同静态目录。

验证：`node --test scripts/installer-preview.test.mjs`。覆盖默认选项、非法路径、目录修改、权限提示、无 D 盘回退演示、暂停、取消、重试、完成摘要、移动端无横向溢出与控制台错误。截图写入 `screenshots/installer-preview/`。

执行 `node scripts/installer-preview-server.mjs --export` 导出单文件交互预览 `screenshots/installer-preview/知屿安装体验.html`。该文件内嵌图标、样式与交互脚本，可直接在浏览器打开，无需安装依赖或启动服务。

原生编译与界面、路径、参数、下载长度和哈希拒绝检查由 `npm run desktop:online` 执行；NSIS 自启与卸载宏另有隔离注册表回归。真实安装与卸载仅在一次性的 GitHub Actions Windows 环境执行，不在维护者日常电脑上试装。真实 UAC 点击、不同 Windows 版本、拒绝授权、磁盘满和第三方安全软件兼容性仍需独立系统环境验收。
