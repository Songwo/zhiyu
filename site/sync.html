      一句话总结

      • 配对码只在你眼前出现：它从不在网络上传输，用一次就作废，错 3 次也作废。
      • 之后不再依赖它：双方记住对方的公钥，每次同步先互相认证，再用临时密钥加密。
      • 即使没有 HTTPS 也行：协议自己负责认证、加密和防重放，HTTPS 是额外一层。
      • 密钥库默认不同步：开启后只传密文，服务器看不到明文；系统保存的 Token 与 API Key 永远不同步。

      完整设计、威胁模型和已知限制见 docs/SYNC.md ↗。这是自研的协议组合（构件均为标准算法和通用库）， 没有经过第三方审计，欢迎审阅。
