# Windows 原生终端

Windows 连接面板由 C# / WPF 原生子控件绘制，使用 `HwndSource` 直接嵌入 Electron 主窗口的终端工作区，不额外打开顶层窗口或任务栏图标。运行时依赖 Windows 的 .NET Framework 4.8，无额外 NuGet 包。为让原生控件参与窗口裁剪，Windows 主进程关闭 Chromium 的独立 DirectComposition 合成路径，保留硬件加速。

`npm run terminal:build` 编译原生控件并执行 C# 状态机、键盘输入与布局测试；`node scripts/native-terminal-integration.mjs` 验证桌面入口、本机临时 SSH 服务、嵌入句柄、外观设置、页面切换和锁定清理。`npm run desktop` 和桌面打包脚本自动编译并携带原生程序。在软件「终端」页点击「终端外观预览」即可查看不连接服务器的代码配色示例。

控件通过继承的标准输入、输出管道传递逐行 UTF-8 JSON。宿主句柄只允许由主进程提供，布局、字体、配色和工具栏输入（常用命令、清屏，单条不超过 4096 字符）有白名单校验。网页端把原生控件在圆角卡片内缩 6px，控件本身保持矩形，不再用固定半径的窗口区域裁剪。凭据不通过命令行或临时文件传递，SSH 认证、密钥库与主机指纹校验复用 `SshManager`。离开终端、切换主机、打开设置及关闭到托盘时隐藏控件并保留会话，返回时恢复原有缓冲、阅读位置与连接。多个主机通过会话标签切换。显式断开只结束对应主机；重连会读取最新凭据；锁定密钥库、系统锁屏或休眠、刷新主页面及完全退出应用会结束全部连接。会话标识不写入资产文件。

SSH 每 20 秒发送协议层保活请求，未响应请求上限配置为 3；保活不会发送 shell 命令，也不承诺在网络已中断后恢复远程进程。集成测试关闭真实应用窗口到托盘，等待本机 SSH 服务收到 `keepalive@openssh.com`，再验证恢复窗口没有新增连接。

外观统一在「设置 → 终端」调整，保存在本机 `sinan-settings-v1` 的 `terminalAppearance`，不写入资产或同步文件；早期 `zhiyu-terminal-appearance-v1` 配置会自动迁移。设置修改即时生效，打开设置或返回会话不会重新连接。默认跟随软件浅色／深色主题，另有柔和暗色、暖纸色；支持 Cascadia Mono、Consolas、JetBrains Mono（未安装时回退）和 11–22 px 字号。原生控件与网页终端共享 ANSI 配色。高亮来自远程工具的 ANSI 输出，不会自动给 `cat` 等纯文本输出增加语法着色。

终端支持 UTF-8、中文双宽、基础 VT 光标与擦除、16/256/真彩色、备用屏幕、滚动区域、方向键、Ctrl+C 和括号粘贴。光标默认为闪烁竖线，可在设置中改为方块、下划线或常亮；终端失去焦点时光标变暗（方块改为描边）。中文等输入法通过 IMM32 把组合窗口和候选框定位到光标处，避免 WPF 自绘控件默认把候选框放在屏幕左上角。历史默认 5000 行，可选 1000、10000、20000 行；原生侧使用环形缓冲限制内存并避免逐行搬移。右侧滚动条可拖动，滚轮和 Shift+PageUp/PageDown 可阅读历史；上翻、选择文字或锁定滚动后，新输出不会抢回底部，按钮可回到最新。Ctrl+Shift+End 同样回到最新。备用屏幕不显示普通输出历史。

多行粘贴需要确认。渲染按帧合并输出并缓存字形；隐藏窗口时更新缓冲但暂停重绘和光标计时。原生输入管道拥塞时暂停 SSH 输出读取，排空后恢复，不主动丢弃日志。复杂全屏应用、分屏和完整的终端协议兼容性仍需另行验证。

macOS、Linux 和网页版也使用同一个终端工作区及外观设置，输出区使用 xterm。网络握手速度取决于服务器、网络与原有 SSH 实现，目前没有进行前后速度基准比较。
